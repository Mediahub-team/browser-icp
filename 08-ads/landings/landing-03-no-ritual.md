# ТЗ для дизайнера — лендинг offer-03-no-ritual / ICP-03

**Источники:** [[offer-03-no-ritual]] · [[icp-03-cashback-optimizers]] · [[product-description]] · [[comparison-2026-06-10]].

> Пред-продуктовый лендинг (waitlist). Честность (K3): без связывающих цифр кешбэка (%/сумма/срок), ничего против инвариантов [[product-functionality]] §2 (кешбэк только через браузер). Заполнено под первичный угол ICP-03.

## 1. Контекст и цель
- **Продукт (1 фраза):** iOS-браузер, который возвращает живые рубли за любую покупку, прошедшую через него.
- **Стадия:** пред-запуск. **Единственная цель:** заявка в лист ожидания (e-mail).
- **Сегмент / угол:** ICP-03 кешбэк-оптимизаторы — мотив контроль/«выжимаю максимум»; **боль:** ритуал переключения сервисов перед каждой покупкой.
- **Откуда трафик:** Telegram (кешбэк-каналы) + Яндекс Директ РСЯ → UTM кампании.
- **Главный KPI:** **CPS** (стоимость заявки) + распределение intent-ответов (§11).

## 2. Аудитория и тон
- **Кто и контекст:** считает ставки, комбинирует агрегатор+категорию+промокод, устал от ритуала; «изменение, которое покупает» — один инструмент вместо зоопарка.
- **Tone of voice:** по делу, с цифрами и без воды; уважительный к «прошарённости» (не объясняет, что такое кешбэк). Спокойный, не «халява».
- **Customer language (дословно в тексты):** «надоело заходить через ссылку», «ловит сам за любой сайт», «пруф вывода», «стек поверх банка».
- **Слова-табу:** «халява», «заработок», «лёгкие деньги», гарантии мгновенного вывода.

## 3. Описание и нарратив страницы
- **Главный вывод (one takeaway):** «Можно перестать жонглировать сервисами — этот браузер ловит кешбэк сам за любой сайт, и выплаты прозрачны».
- **Логика убеждения:** боль ритуала → обещание «ловит сам за любой сайт» → почему верить (прозрачный статус + пруфы, по оферте) → лёгкое действие (waitlist).

## 4. Структура секций (сверху вниз)
1. **Hero.** H1 (посыл оффера) + подзаголовок (механика «ловит сам, любой сайт») + CTA «Записаться в лист ожидания» + честный мокап браузера с бейджем «+кешбэк».
2. **Ценность — 3 буллета:** без ритуала / за любой сайт / стек поверх банка.
3. **Demo «как это работает».** 3 шага: покупаешь как обычно в браузере → покупка фиксируется сама (без ссылок) → кешбэк рублями на баланс.
4. **Доверие / честность.** Статус-трекер «Проверяем → Подтверждено → Выплачено»; «по оферте»; честная граница: «детект на нейтральных сайтах в развитии — покажем, где уже работает»; анти-«обманут».
5. **Форма waitlist.** E-mail + кнопка → intent-блок (§11).
6. **Соц.доказательство.** Плейсхолдеры цитат оптимизаторов + счётчик ожидающих.
7. **Футер.** Короткий; оферта/политика.

## 5. Копирайтинг
- **H1 (≤~60):** «Покупай как обычно — кешбэк ловится сам».
- **Подзаголовок (≤~120):** «Один браузер вместо пяти сервисов: возврат за любой сайт, без захода через ссылки».
- **CTA-копи:** «Записаться в лист ожидания» *(повтор после demo)*.
- **3 буллета:** «Без ритуала — не надо заходить через ссылки» · «За любой сайт, не только партнёры» · «Стеком поверх твоего банка».
- **Заголовок demo:** «Как это работает»; шаги: «1. Покупаешь в браузере как обычно» · «2. Покупка фиксируется сама» · «3. Кешбэк рублями — видно на каждом шаге».
- **Блок доверия:** «Каждый рубль виден: начислили → подтвердили → вывели. Выплата по публичной оферте.»
- **Лейбл/плейсхолдер формы:** «Ваш e-mail».
- **Микрокопи под формой:** «Не спамим. Напишем, когда откроем доступ».
- **Спасибо:** «Вы в списке. Спасибо!».
- **Ошибка формы:** «Проверьте e-mail».

## 6. Обязательные элементы конверсии
- CTA дважды (hero + после demo), визуально приоритетна. Форма — только e-mail. Intent-блок после заявки (§11). Без давления/таймеров.

## 7. Визуальная иерархия и стиль
- Приоритет: H1 → CTA → demo → доверие. Акцентный цвет — на CTA.
- Палитра/настроение: бренд-токены (индиго-синий + зелёный акцент, светлый фон, Golos Text — `08-ads/tools/landing/design-system.css`); «разгрузка, стало просто».
- Imagery: честные мокапы браузера; без фото-стоков и фейк-скринов.

## 8. Адаптив и состояния
- Mobile-first; брейкпоинты 360–430 / 768 / 1200+. Состояния формы: default/focus/loading/success/error. CTA: default/hover/disabled.

## 9. Доступность
- Контраст ≥ WCAG AA; tap-target ≥ 44×44; видимый focus; alt; семантический HTML; клавиатурная навигация.

## 10. Технические требования
- Адаптив, быстрая загрузка. Форма → цель Метрики «waitlist_signup»; UTM из URL. Без сторонних трекеров.

## 11. Intent-сигнал и измерение
- После заявки: «Что для вас главное?» — варианты: «Чтобы ловило само за любой сайт» / «Чтобы не зажали выплату (пруфы)» / «Размер ставки» *(контроль «кешбэк вообще»)*; чекбокс «Готов(а) попробовать первым(ой) и оставить отзыв».
- **Критерий успеха:** CPS ≤ порога [[test-plan]]; распределение intent (что важнее — «без ритуала» или «доверие/ставка») — вход для этапа 9.

## 12. Что НЕ делать
- Не обещать % / сумм / сроков кешбэка; ничего против инвариантов. Без слов-табу. Цель — не установка приложения (его ещё нет). Без давления/таймеров.

## 13. Референсы и deliverables
- **Референсы:** «эталон на бренде» — `08-ads/tools/landing/` (генератор + design-system.css).
- **Deliverables:** макет (mobile + desktop), исходник, спецификация состояний формы, экспорт ассетов, спека брейкпоинтов.
