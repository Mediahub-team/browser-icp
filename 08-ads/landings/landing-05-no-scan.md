# ТЗ для дизайнера — лендинг offer-05-no-scan / ICP-05

**Источники:** [[offer-05-no-scan]] · [[icp-05-family-shoppers]] · [[product-description]] · [[market-landscape]] §3.

> Пред-продуктовый лендинг (waitlist). Угол «копится без сканов» с **прямой отстройкой от Едадила/кешбэка-по-чекам**. Честность: без связывающих цифр, ничего против инвариантов.

## 1. Контекст и цель
- **Продукт (1 фраза):** браузер, который возвращает живые рубли за покупки через него.
- **Стадия:** пред-запуск. **Цель:** заявка в лист ожидания.
- **Сегмент / угол:** ICP-05 семейные закупщики — мотив экономия/контроль бюджета; **боль:** мелочь мимо кешбэка + скан чеков надоел.
- **Откуда трафик:** VK/Telegram родительские сообщества + инфлюенсер → UTM.
- **Главный KPI:** CPS + intent (важно ли «без сканов»).

## 2. Аудитория и тон
- **Кто и контекст:** закупает на семью часто и помногу мелких позиций; времени нет, ритуалы не любит; «изменение» — со всех трат копится само.
- **Tone of voice:** тёплый, «для своих», простой; без жаргона.
- **Customer language (дословно):** «сто заказов в месяц мимо кешбэка», «сканировать чеки надоело», «копится со всего», «накопила за месяц».
- **Слова-табу:** «партнёрские ставки», финтех-жаргон, всё, что звучит как «ещё одна задача».

## 3. Описание и нарратив страницы
- **Главный вывод:** «Со всех моих семейных покупок кешбэк копится сам — без сканов чеков и возни».
- **Логика убеждения:** боль (мелочь мимо + скан надоел) → обещание «копится со всего само, без сканов» → почему верить (авто, прозрачно, на карту) → waitlist.

## 4. Структура секций
1. **Hero.** H1 (копится без сканов) + подзаголовок (со всех покупок через браузер) + CTA waitlist + тёплый визуал растущего баланса.
2. **Ценность — 3 буллета:** без сканов чеков / со всех покупок, не только список / на карту, прозрачно.
3. **Demo.** 3 шага: покупаешь для семьи через браузер → кешбэк со всего сам → накопленное на карту.
4. **Доверие / честность.** Авто-детект (без сканов) как механика; по оферте; честная граница «работает за покупки через браузер» (часть закупок в приложении/офлайн — не покрывается); анти-«ещё одна морока».
5. **Форма waitlist** → intent (§11).
6. **Соц.доказательство.** Плейсхолдеры цитат мам + счётчик.
7. **Футер** короткий.

## 5. Копирайтинг
- **H1 (≤~60):** «Копится со всех покупок — без сканов чеков».
- **Подзаголовок (≤~120):** «Закупаешься на семью через браузер — кешбэк со всего сам, на карту».
- **CTA-копи:** «Записаться в лист ожидания».
- **3 буллета:** «Без сканов чеков и ссылок» · «Со всех покупок, не только из списка» · «Накопленное — на карту».
- **Заголовок demo:** «Как это работает»; шаги: «1. Покупаешь для семьи через браузер» · «2. Кешбэк со всего копится сам» · «3. Выводишь накопленное на карту».
- **Блок доверия:** «Никаких сканов и списков позиций — кешбэк со всех покупок сам. По оферте. Мы на старте — это лист ожидания».
- **Форма:** «Ваш e-mail»; микрокопи: «Без спама. Напишем, когда откроем».
- **Спасибо:** «Вы в списке. Спасибо!»; **Ошибка:** «Проверьте e-mail».

## 6. Обязательные элементы конверсии
- CTA дважды; форма — только e-mail; intent-блок; без давления.

## 7. Визуальная иерархия и стиль
- Приоритет: H1 → CTA → demo → доверие. Акцент на CTA.
- Палитра: бренд-токены; настроение тёплое, «семейное», без глянца-стока. Imagery: честный визуал накопления баланса; реальные мам-отзывы (плейсхолдеры).

## 8. Адаптив и состояния
- Mobile-first (аудитория с телефона); 360–430 / 768 / 1200+. Форма: default/focus/loading/success/error. CTA-состояния.

## 9. Доступность
- Контраст ≥ AA; tap ≥ 44×44; focus; alt; семантика; клавиатура.

## 10. Технические требования
- Адаптив, быстрая загрузка. Форма → цель Метрики «waitlist_signup»; UTM. Без лишних трекеров.

## 11. Intent-сигнал и измерение
- После заявки: «Что для вас главное?» — «Чтобы без сканов чеков» / «Чтобы копилось со всего» / «Размер кешбэка» *(контроль)*; чекбокс «Готов(а) попробовать первой и оставить отзыв».
- **Критерий успеха:** CPS ≤ порога [[test-plan]]; доля «без сканов» — подтверждение отстройки от Едадила; gate-риск по конверсии.

## 12. Что НЕ делать
- Не обещать сумм/сроков. Без жаргона и «ещё одной задачи». Без давления. Цель — waitlist. Ничего против инвариантов.

## 13. Референсы и deliverables
- **Референсы:** `08-ads/tools/landing/`.
- **Deliverables:** макет (mobile + desktop), исходник, спецификация состояний формы, ассеты, брейкпоинты.
