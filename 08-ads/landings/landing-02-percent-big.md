# ТЗ для дизайнера — лендинг offer-02-percent-big / ICP-02

**Источники:** [[offer-02-percent-big]] · [[icp-02-site-big-checks]] · [[product-description]] · [[market-landscape]] §2.1/§8.

> Пред-продуктовый лендинг (waitlist). Угол **%/гибрид на крупных** (фикс не упоминаем). ⚠️ **Под гейтом фиксации партнёрской %-сетки:** без конкретных % на странице, пока не зафиксированы. Честность: без связывающих цифр, ничего против инвариантов.

## 1. Контекст и цель
- **Продукт (1 фраза):** браузер, который возвращает живые рубли за покупки через него.
- **Стадия:** пред-запуск. **Цель:** заявка в лист ожидания.
- **Сегмент / угол:** ICP-02 крупные чеки — мотив экономия (величина возврата)/контроль; **боль:** на крупной покупке вне «категории месяца» банка возврат мизерный, лимит режет.
- **Откуда трафик:** Яндекс Директ Поиск (горячий спрос на крупную покупку) + РСЯ-ретаргет → UTM.
- **Главный KPI:** CPS (дорогой, редкий) + intent (важен ли %).

## 2. Аудитория и тон
- **Кто и контекст:** покупает дорогое с сайта, считает выгоду в рублях, меняли карту ради кешбэка; «изменение» — ощутимый % на крупном, не привязанный к категории месяца.
- **Tone of voice:** рационально, для считающих; без эмоций, цифры (но без конкретных % до сетки).
- **Customer language (дословно):** «дайте процент, а не десять рублей», «категория не та вечно», «а лимит есть?», «на крупном чеке».
- **Слова-табу:** «фикс», «10 рублей», «копейки»; **конкретные % партнёров до фиксации сетки**.

## 3. Описание и нарратив страницы
- **Главный вывод:** «На дорогих покупках здесь возвращают процентом — и он не зависит от угаданной категории месяца».
- **Логика убеждения:** боль (мизер вне категории + лимит) → обещание «% на крупных, без категории» → почему верить (у партнёров, по оферте, пруф крупной выплаты) → waitlist.

## 4. Структура секций
1. **Hero.** H1 (% на крупных) + подзаголовок (без категории месяца/лимита) + CTA waitlist + рациональный визуал «крупная покупка → % возврата» (без числа).
2. **Ценность — 3 буллета:** процент на дорогих / без категории месяца / без лимита повышенного кешбэка.
3. **Demo.** 3 шага: открываешь крупную покупку через браузер → % у партнёра → ощутимый возврат рублями.
4. **Доверие / честность.** % у партнёров; по оферте; честная граница «повышенный % у партнёров — сетка формируется, покажем где»; пруф крупной выплаты; анти-«зажмут на большой сумме».
5. **Форма waitlist** → intent (§11).
6. **Соц.доказательство.** Плейсхолдеры + счётчик.
7. **Футер** с правовыми ссылками.

## 5. Копирайтинг
- **H1 (≤~60):** «Процент на крупных покупках — без категории месяца».
- **Подзаголовок (≤~120):** «Дорогая покупка через браузер — повышенный % у партнёров, без лимита банка».
- **CTA-копи:** «Записаться в лист ожидания».
- **3 буллета:** «Процент на дорогих, не фикс» · «Без категории месяца» · «Без лимита повышенного кешбэка».
- **Заголовок demo:** «Как это работает»; шаги: «1. Открываешь крупную покупку через браузер» · «2. Повышенный % у партнёра» · «3. Ощутимый возврат рублями».
- **Блок доверия:** «Процент у партнёров — сетку формируем, покажем честно где и сколько. Выплата по оферте. Мы на старте — это лист ожидания».
- **Форма:** «Ваш e-mail»; микрокопи: «Без спама. Позовём, когда откроем».
- **Спасибо:** «Вы в списке. Спасибо!»; **Ошибка:** «Проверьте e-mail».

## 6. Обязательные элементы конверсии
- CTA дважды; форма — только e-mail; intent-блок; без давления.

## 7. Визуальная иерархия и стиль
- Приоритет: H1 → CTA → demo → доверие. Акцент на CTA.
- Палитра: бренд-токены; настроение «рационально, надёжно». Imagery: схема «крупная покупка → % возврата» **без конкретного числа**; без стоков.

## 8. Адаптив и состояния
- Mobile-first, desktop важен (часть на ПК перед крупной покупкой); 360–430 / 768 / 1200+. Форма: default/focus/loading/success/error. CTA-состояния.

## 9. Доступность
- Контраст ≥ AA; tap ≥ 44×44; focus; alt; семантика; клавиатура.

## 10. Технические требования
- Адаптив, быстрая загрузка. Форма → цель Метрики «waitlist_signup»; UTM. Без лишних трекеров.

## 11. Intent-сигнал и измерение
- После заявки: «Что для вас главное?» — «Чтобы был ощутимый процент» / «Чтобы без категории месяца» / «Размер кешбэка вообще» *(контроль)*; чекбокс «Готов(а) попробовать первым(ой)».
- **Критерий успеха:** CPS ≤ порога [[test-plan]] (ожидается дорогой); intent подтверждает спрос на %-модель (вход в модель×профиль для этапа 9).

## 12. Что НЕ делать
- **Не указывать конкретные %** до фиксации сетки; не обещать сумм/сроков. Не упоминать «фикс». Без давления. Цель — waitlist. Ничего против инвариантов.

## 13. Референсы и deliverables
- **Референсы:** `08-ads/tools/landing/`.
- **Deliverables:** макет (mobile + desktop), исходник, спецификация состояний формы, ассеты, брейкпоинты.
