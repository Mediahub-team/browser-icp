# Лендинги — ICP-02 Контент-читатели (мотив A, O4–O6, пред-продукт / waitlist)

> Спека пред-продуктовых лендингов под [[offer-icp02-summary]]. Продукт НЕ запущен:
> CTA = **«Записаться в лист ожидания»** (email). Меряем притяжение обещания + качество
> интента, НЕ установку. Инструментовка интента — из [[recheck-preproduct-landing-2026-06-04]].
> Сквозная механика всех трёх: **«ИИ видит твой экран — суть прямо на открытой странице,
> без копипаста»**. Никакого «нейросеть/LLM/промпт» — давим на механику, не интеллект.

## Общий каркас лендинга (одинаков для L-O4 / L-O5 / L-O6)
1. **Hero** — заголовок-крючок под оффер (ниже) + **подзаголовок-механика**:
   «ИИ работает прямо на открытой странице. Не надо копировать текст, переключать
   вкладки или логиниться в чат — суть появляется там же, где ты читаешь.»
2. **3 буллета** — выгода под оффер (ниже).
3. **Демо-блок** — анимация/видео-петля «открыл страницу → один тап → суть выезжает
   поверх ТОЙ ЖЕ страницы»; подпись «без копипаста». Кнопка «посмотреть, как это работает»
   (клик логируем как сигнал интереса).
4. **CTA — «Записаться в лист ожидания»** (поле email + кнопка).
5. **Вторичный интент-сигнал (после заявки):**
   - микро-вопрос «**Что для вас главное?**» (1 выбор): «суть из ленты каналов» /
     «суть рабочего документа до созвона» / «разгрести сохранёнки» / «другое»;
   - чекбокс микро-коммитмента «**Готов попробовать первым / оставить отзыв**».
6. **Доверие (короткий слой):** «суть привязана к месту в тексте — видно, откуда взято»
   + «текст не уходит во внешний чат» (особенно для L-O5).

## L-O4 — «Суть из ленты» (Telegram/дайджест → этот лендинг)
- **Hero (заголовки, A/B):**
  1. «Десять каналов за пять минут. Тап — и суть, без копипаста.»
  2. «Лента разрослась? Тап по посту — 3 буллета сути прямо на экране.»
  3. «ИИ видит то, что у тебя в ленте. Суть поста за секунды — без пересылки боту.»
- **Подзаголовок:** механика «без копипаста» (см. общий каркас).
- **3 буллета:**
  - «Пробеги ленту канала за минуту — тап по посту, и суть без скролла.»
  - «Ничего не копируешь и никуда не пересылаешь — ИИ читает прямо открытый пост.»
  - «10–30 каналов? Лови главное за день, не утонув в скролле.»
- **Демо-блок:** «длинный пост → тап → 3 буллета поверх поста».
- **Микро-вопрос — приоритетный ответ:** «суть из ленты каналов».

## L-O5 — «Суть из простыни / до созвона» (VK профсообщества, РСЯ → этот лендинг)
- **Hero (заголовки, A/B):**
  1. «Суть из простыни — до созвона. Без копипаста наружу.»
  2. «Дай суть из документа. ИИ читает прямо страницу — текст не уходит во внешний чат.»
  3. «Не успел прочитать к созвону? Тап — суть и цифры, со ссылкой на абзац.»
- **Подзаголовок:** механика «без копипаста» + «текст не уходит наружу».
- **3 буллета:**
  - «За минуту владеешь длинным материалом — суть и ключевые цифры в один тап.»
  - «Ничего не копируешь во внешний чат — важно, где ChatGPT под запретом.»
  - «Источник под рукой: сошлёшься на абзац, а не на пересказ.»
- **Демо-блок:** «отчёт/лонгрид → тап → суть + цифры, буллет кликается к абзацу-источнику».
- **Микро-вопрос — приоритетный ответ:** «суть рабочего документа до созвона».

## L-O6 — «Разгрести сохранёнки» (Telegram/VK → этот лендинг)
- **Hero (заголовки, A/B):**
  1. «Сто непрочитанных лонгридов? Суть каждой — в один тап. Без копипаста.»
  2. «Сохранил — будто прочитал? Открой из избранного: тап — и суть.»
  3. «Избранное как кладбище? Разгреби — ИИ даёт суть прямо на странице.»
- **Подзаголовок:** механика «без копипаста» (см. общий каркас).
- **3 буллета:**
  - «Сто сохранёнок → суть каждой в один тап, без копипаста.»
  - «Открыл из избранного — ИИ читает прямо страницу, переносить ничего не надо.»
  - «Закрой вину за непрочитанное: кладбище превращается в «прочитано».»
- **Демо-блок:** «открыл из избранного → тап → суть», счётчик «разобрано N из 100».
- **Микро-вопрос — приоритетный ответ:** «разгрести сохранёнки».

## Что меряем (на всех трёх лендингах)
- **CTR** объявления → визит лендинга (на стороне таргетинга, см. targeting/icp02.md).
- **signup-rate:** визит лендинга → заявка в лист ожидания.
- **cost-per-signup.**
- **Качество интента (главный фокус пред-продукта):**
  - доля микро-коммитмента «готов попробовать первым»;
  - распределение ответов вторичного микро-вопроса (сходится ли мотив с углом лендинга);
  - scroll-depth до демо-блока + клик «посмотреть, как это работает».
- **Решение по офферам:** ранг по **signup × качество интента**, НЕ по числу заявок
  (заявка дешева → raw-signup переоценивает реальную конверсию).
- **Kill-критерий на лендинг:** cost-per-signup выше X ИЛИ доля микро-коммитмента ниже Y.
