# Сегментные варианты лендинга

База — реальный бренд-лендинг (Figma Make: `src/imports/Landing1440Light`). На его основе
делаем **варианты по сегментам** через `?v=<id>` в URL (UTM из объявления → нужный вариант).
Одна сборка обслуживает все варианты A/B-теста.

## Запуск
```
npm install      # один раз (pnpm нет — используем npm)
npm run dev      # http://localhost:5173/?v=s
npm run build    # dist/
npx vite preview --port 4173   # http://localhost:4173/?v=power
```

## Варианты (`src/app/variants.ts`)
| `?v=` | Сегмент | Hero | Секции |
|---|---|---|---|
| (нет) / `base` | Кешбэк (база) | «Возвращайте до 30%» | все |
| `cashback` | ICP-05/06 кешбэк-доверие | «Кешбэк, который реально выводится» | все |
| `s` | ICP-04 (S) проверь товар | «Проверь товар до покупки» | smart-блок (нейросеть/цена) |
| `a` | ICP-02 (A) суть страницы | «Суть любой статьи — в один тап» | smart-блок |
| `students` | ICP-03 студенты | «Разберись в теме — со ссылками» | пилюли + smart-блок |
| `power` | ICP-01 AI-power | «ИИ на открытой странице» | smart-блок |

Меняются: **hero** (через `VariantContext` в `Landing1440Light`), **набор секций**
(условный рендер в корневом компоненте) и **копия формы** (`WaitlistModal`).

## Флаги секций (выверено по DOM)
- `marketplaces` (Content1) — пилюли «Работает везде» (кешбэк %)
- `steps` (Content3) — второстепенный блок (баланс/задания)
- `compare` (Content4) — «Как покупать выгоднее в 3 шага» + тизер ассистента
- `reviews` (Content6) — «Один товар. Лучшая цена» + «Нейросеть против заказных отзывов» (smart)

## Форма (`WaitlistModal`)
Табы Email/Телефон → success. В success добавлен **интент-блок** (микро-вопрос по сегменту
+ чекбокс «готов попробовать первым») — для замера качества заявок (см. `08-ads/test-plan.md`).
⚠️ Сабмит — заглушка; для боевого теста подключить приём заявок + цель Метрики «waitlist_signup».
