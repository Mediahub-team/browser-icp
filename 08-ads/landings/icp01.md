# Лендинг (спека) — ICP-01 AI-power-users (мотив A, угол «убери копипаст»)

> ⚠️ **Пред-продуктовый лендинг-тест.** Продукт НЕ запущен: лендинг + CTA = лист ожидания.
> Меряем не использование, а **притяжение обещания**. Только **механика** (НЕ «умный
> ассистент» — субституция ChatGPT). **Без кешбэка/шопинга** в посыле. Источник:
> [[offer-icp01-power]], [[recheck-preproduct-landing-2026-06-04]].

## Hero (механика без копипаста)
- **H1:** «Хватит быть курьером между вкладкой и чатом».
- **Подзаголовок:** «ИИ работает с открытой страницей и вебом — спрашиваешь прямо на ней.
  Без копипаста и переключения вкладок».
- **Первичный CTA:** **«Записаться в лист ожидания»** (email).
- **Визуал hero:** before/after — слева перетаскивание текста из вкладки в чат, справа ответ
  ИИ поверх той же страницы (стрелок нет).

## 3 буллета (выгоды, только механика)
1. **Не копируешь — ИИ видит страницу.** Открыл → спросил → ответ по тому, что на экране.
2. **Работает там, где копировать нельзя:** мобайл, PDF, контент за логином.
3. **4 вкладки → одна таблица «суть / риск / что делать»** — мульти-таб синтез без ручной сводки.

## Демо-блок
- **Демо 1 — «не копируешь — ИИ видит страницу» (O9):** короткий цикл before/after.
  Before: выделить → переключиться в ChatGPT → вставить → ждать. After: открыл страницу →
  спросил → ответ по ней. Подпись: «ИИ читает ту самую страницу, что открыта — даже PDF / за логином».
- **Демо 2 — мульти-таб синтез (O10):** 4 открытые вкладки → один тап → таблица
  «суть / риск / что делать» со ссылками на источники; колонка «риск» подсвечивает расхождения.
  Подпись: «4 ссылки → сводная таблица, без копипаста между вкладками».

## CTA-блок
- **Основной CTA (повтор):** **«Записаться в лист ожидания»**.
- **Вторичный интент-сигнал (после заявки):**
  - Микро-вопрос «Что для вас главное?» → выбор: *спросить прямо на странице* /
    *страницы за логином и PDF* / *свести несколько вкладок в таблицу* / *просто интересно*.
    («просто интересно» = маркер любопытства/низкого интента.)
  - Микро-коммитмент (чекбокс): «Готов попробовать первым и оставить отзыв».
  - **НЕ предлагаем** «кешбэк» как вариант — этого угла на лендинге нет вовсе.

## Что меряем
- CTR объявления → лендинг.
- **signup-rate** (визит → заявка в лист ожидания), **cost-per-signup**.
- **Качество интента:** доля микро-коммитмента + распределение ответов микро-вопроса
  (доля «просто интересно» vs конкретные механические сценарии).
- Вспом.: scroll-depth до демо-блока, клик по вторичному CTA.

## Kill-критерий (зафиксирован заранее)
Выключаем ячейку, если по итогам стартового бюджета выполнено **любое**:
1. **cost-per-signup выше порога X** (дороже фокус-ячеек S / A-контент).
2. **Доля микро-коммитмента ниже Y** → заявки из любопытства, не интент.
3. **В микро-вопросе доминирует «просто интересно»** → подтверждение низкого интента / субституции ChatGPT.

→ kill-fast, бюджет не переливаем. Это **дешёвый эксперимент**: цель — дёшево проверить
угол механики и при слабом сигнале быстро выйти.
