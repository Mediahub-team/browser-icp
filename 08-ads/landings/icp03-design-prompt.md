# Промт для AI-генерации лендинга — «Кэшбэк Браузер» (ICP-03 Студенты)

> Готовый промт для Claude (Artifacts) — ядро универсальное (v0/Lovable/Bolt тоже подойдут).
> Угол: «разберись со ссылками, не выдумкой». Доминанта — **доверие к источникам /
> анти-галлюцинации**, не скорость. Кешбэк — вторая выгода, тест co-C отдельным блоком.

## Как пользоваться
1. Скопируй блок ПРОМТ целиком. 2. Вставь в Claude. 3. Получишь адаптивный лендинг одним
файлом. 4. Проверь по чек-листу внизу. По умолчанию генерь **O8-версию** (с кешбэк-блоком);
для **O7** попроси убрать секцию кешбэка и вариант «кешбэк» из микро-вопроса.

---

## ПРОМТ (копировать целиком)

```
Ты — продуктовый веб-дизайнер и фронтендер. Сделай ОДНОСТРАНИЧНЫЙ адаптивный лендинг
(mobile-first) одним самодостаточным файлом: HTML + Tailwind (CDN) + минимум JS.
Никаких внешних зависимостей кроме Tailwind CDN. Верни один файл, готовый открыть в браузере.

КОНТЕКСТ ПРОДУКТА (пред-запуск, продукт ещё не вышел):
Браузер с ИИ-ассистентом, который видит открытую страницу и ищет по вебу. Ведущая ценность
для этой аудитории — ответ ВСЕГДА с проверяемым источником: цитата в кавычках + ссылка на
конкретный абзац источника (анти-галлюцинации), в отличие от ChatGPT, который выдумывает
ссылки и факты.
ЧЕСТНОСТЬ (обязательно соблюдать, не приукрашивать): продукт ещё в листе ожидания, не
запущен; кешбэк — БЕЗ конкретных процентов и сроков, только низкий порог вывода «от 100 ₽»;
это помощник РАЗОБРАТЬСЯ, а не «решала» / «сделать ДЗ за тебя».

ЦЕЛЬ СТРАНИЦЫ: единственное целевое действие — оставить заявку в ЛИСТ ОЖИДАНИЯ (e-mail).
Продукт ещё не запущен — не предлагай «скачать приложение».

АУДИТОРИЯ И ТОН: студенты и самообучающиеся 17–25, всё с телефона, дедлайны (курсовая /
диплом / защита), тонкий бюджет. Мотив A (разобраться) + co-мотив C (вернуть часть денег).
Тон — свой и живой, без канцелярита; объясняй МЕХАНИКУ доверия к источнику, а не хвали
«умную нейросеть». Доминанта — доверие к источникам, НЕ скорость.
ЯЗЫК (вставь дословно в тексты): «помоги разобраться», «покажи, где это в тексте»,
«ChatGPT бесплатный, чем вы лучше», «сдать без страха спалиться на фейке».
СЛОВА-ТАБУ (не употреблять): канцелярит, «образовательная экосистема», «нейро / LLM /
агент / тул», «сделаем ДЗ за тебя», «решала»; не делай скорость главным обещанием.

СТРУКТУРА (сверху вниз):
1. Hero: H1 = «Разберись в теме быстро — с проверяемыми источниками, а не выдумкой»;
   подзаголовок = «ChatGPT выдумывает ссылки и факты, которых нет. Наш ИИ показывает цитату
   и место в тексте источника — видно, где это написано. Сдавай без страха спалиться на
   фейке.»; кнопка CTA «Записаться в лист ожидания» + поле e-mail. Рядом — мини-демо: ответ
   с подсвеченной цитатой и кликом на абзац источника.
2. Три буллета ценности: «Каждый факт — с пруфом» (привязан к источнику и абзацу);
   «Покажи, где это в тексте» (видно цитату и место, не перепроверяешь вслепую);
   «Безопасно для диплома/курсовой» (битых и выдуманных ссылок нет).
3. Demo-блок «ответ + источник»: слева вопрос студента по теме диплома; справа ответ ИИ →
   кликабельная цитата в кавычках → раскрывается источник с ПОДСВЕЧЕННЫМ абзацем и стрелкой
   «вот здесь в тексте». Контраст-плашка: «ChatGPT: ссылка ведёт в 404» vs «у нас: цитата +
   абзац источника». Схематичный мокап, без фото-стоков.
4. Блок доверия: сними возражение «ChatGPT бесплатный, чем вы лучше» — он выдумывает, мы
   показываем источник. Честная граница: лист ожидания, кешбэк без %/сроков, не «решала».
5. ОТДЕЛЬНЫЙ кешбэк-блок (co-мотив C) ниже демо, второстепенный по весу: «И возвращай
   часть денег с покупок — кешбэк за обычные заказы (учебники, доставка, гаджеты). Вывод
   от 100 ₽, без холда 600 ₽.» Без процентов и сроков. (Для O7-версии этот блок убрать.)
6. Форма waitlist: поле e-mail + кнопка. ПОСЛЕ отправки показать intent-блок:
   - вопрос «Что для вас главное?» с вариантами: «проверяемые источники», «разобрать тему
     быстро», «безопасно для диплома», «кешбэк с покупок» (последний — контрольный);
   - чекбокс «Готов попробовать первым и оставить отзыв».
   (JS: по сабмиту прятать форму, показывать intent-блок и «спасибо»; данные никуда не
   шлём — заглушка.)
7. Лёгкое соц.доказательство (плейсхолдеры) + короткий футер.

ДИЗАЙН: mobile-first, чистая типографика, спокойная «учебная» палитра; акцент-цвет только
на подсветке цитаты и кнопке CTA. Без таймеров, без «осталось N мест», без давления.
Доступность (контраст, размеры тапа). Семантический HTML.

ИЗМЕРЕНИЕ (заглушки, без реальных ключей): предусмотри место под цель Метрики
«waitlist_signup» (data-атрибут на форме) и чтение UTM (utm_source/medium/campaign/content)
из URL.

Верни ТОЛЬКО код одного файла.
```

## Чек-лист после генерации
- [ ] CTA = «лист ожидания», нет «скачать приложение».
- [ ] Доминанта — источники/анти-галлюцинации, скорость не главное обещание.
- [ ] Нет слов-табу; использован customer language дословно.
- [ ] Demo-блок: цитата + подсвеченный абзац источника + контраст с «404» у ChatGPT.
- [ ] Есть intent-блок после заявки (микро-вопрос + чекбокс).
- [ ] Кешбэк — отдельным второстепенным блоком, без %/сроков, порог «от 100 ₽» (O8); в O7 убран.
- [ ] Mobile-first, адаптивно, без давления/таймеров.
