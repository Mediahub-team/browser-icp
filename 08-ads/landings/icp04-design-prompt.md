# Промт для AI-генерации лендинга — «Проверь товар» / ICP-04 Тревожные покупатели (мотив S)

> Готовый промт для сервиса генерации дизайна/кода. **Главный таргет — Claude (Artifacts)**;
> ядро универсальное (v0/Lovable/Bolt/любой LLM). Плейсхолдеры подставлены под ICP-04
> (мотив S, оффер «проверь товар до покупки»). Вставь блок «ПРОМТ» целиком в сервис.

## Как пользоваться
1. Блок ПРОМТ уже заполнен под ICP-04. 2. Вставь в Claude (или иной сервис). 3. Получишь
адаптивный лендинг одним файлом. 4. Проверь по чек-листу внизу.

---

## ПРОМТ (копировать целиком)

```
Ты — продуктовый веб-дизайнер и фронтендер. Сделай ОДНОСТРАНИЧНЫЙ адаптивный лендинг
(mobile-first) одним самодостаточным файлом: HTML + Tailwind (CDN) + минимум JS.
Никаких внешних зависимостей кроме Tailwind CDN. Верни один файл, готовый открыть в браузере.

КОНТЕКСТ ПРОДУКТА (пред-запуск, продукт ещё не вышел):
iOS-браузер с ИИ-ассистентом; на маркетплейсах ИИ проверяет товар — разбирает отзывы,
историю продавца и риск подделки и даёт честный вердикт за секунды, ещё до оплаты.
ЧЕСТНОСТЬ (обязательно соблюдать, не приукрашивать): глубокий разбор товара пока только
на Ozon (для остального — сравнение и проверка отзывов); кешбэк/выгоду не обещаем цифрами;
оценка независимая — «не зарабатываем на продавцах».

ЦЕЛЬ СТРАНИЦЫ: единственное целевое действие — оставить заявку в ЛИСТ ОЖИДАНИЯ (e-mail).
Продукт ещё не запущен — не предлагай «скачать приложение».

АУДИТОРИЯ И ТОН: тревожный/осторожный покупатель 28–50, который хоть раз обжёгся и теперь
перепроверяет каждую значимую покупку; боится подделки, накрутки отзывов и ненадёжного
продавца; скептичен к рекламе. Мотив S — уверенность/контроль. Тон СПОКОЙНЫЙ и ЧЕСТНЫЙ,
«свой человек, который скажет как есть», без азарта и нажима.
ЯЗЫК (вставь дословно в тексты): «а вдруг подделка», «отзывам не верю — половина куплена,
нужен кто-то честный», «по три дня выбираю, лишь бы не нарваться на подделку»,
«не хочу выкинуть деньги», «продавец надёжный?».
СЛОВА-ТАБУ (не употреблять): «успей», «скидка только сегодня», «выгодно», таймеры,
«осталось N мест», восклицательный хайп.

СТРУКТУРА (сверху вниз):
1. Hero: H1 = «Проверь товар до покупки — ИИ оценит продавца, отзывы и риск подделки за
   секунды»; подзаголовок = «Обжёгся хоть раз — больше не хочется. Покажем, можно ли верить
   продавцу и отзывам, ещё до того как ты заплатишь. Честно и независимо»; кнопка CTA
   «Записаться в лист ожидания».
2. Три буллета ценности:
   - «Честный вердикт за секунды» — вместо часов вычитывания отзывов; «похоже на риск» или
     «можно верить», без магических цифр;
   - «Видно, на чём вердикт» — разбор отзывов (ok / warn / накручено), история продавца
     (возраст, возвраты, жалобы), признаки подделки; не «доверься нам», а «вот доказательства»;
   - «Независимая оценка» — «не зарабатываем на продавцах», поэтому говорим как есть.
3. Demo-блок: схематичный мокап телефона с карточкой товара и панелью вердикта ИИ (без
   фото-стоков). Показать три строки — Отзывы (ok / warn / «похоже на накрутку»), Продавец
   (возраст, возвраты, жалобы), Риск подделки → итог. Дать ДВА примера: «зелёный» (выглядит
   надёжно) и «красный» (похоже на риск, лучше другой продавец) — инструмент не всегда
   говорит «покупай».
4. Блок доверия: плашка «Мы не зарабатываем на продавцах. Оценка независимая» + честная
   граница «Сейчас глубокий разбор — на Ozon; для остального — сравнение и проверка отзывов».
5. Форма waitlist: поле e-mail + кнопка «Записаться в лист ожидания». Микрокопия «Без спама.
   Напишем, когда откроем доступ — попробуешь одной из первых». ПОСЛЕ отправки показать
   intent-блок:
   - вопрос «Что для вас сейчас главное?» с вариантами: «Проверить товар на подделку / риск»,
     «Понять, надёжен ли продавец», «Разобраться, какие отзывы честные», «Кешбэк / экономия»
     (контрольный вариант);
   - чекбокс «Готов(а) попробовать первым и оставить отзыв».
   (JS: по сабмиту прятать форму, показывать intent-блок и «спасибо»; данные никуда не шлём —
   заглушка.)
6. Лёгкое соц.доказательство (плейсхолдеры-цитаты в голосе сегмента, бейдж «Оценка не зависит
   от продавцов») + короткий футер.

ДИЗАЙН: mobile-first, чистая типографика, спокойная надёжная палитра (сине-серая, мягкие
акценты), без «распродажного» красно-жёлтого. Без таймеров, без «осталось N мест», без
давления. Доступность (контраст, размеры тапа). Семантический HTML.

ИЗМЕРЕНИЕ (заглушки, без реальных ключей): предусмотри место под цель Метрики
«waitlist_signup» (data-атрибут на форме) и чтение UTM из URL.

Верни ТОЛЬКО код одного файла.
```

## Чек-лист после генерации
- [ ] CTA = «лист ожидания», нет «скачать приложение».
- [ ] Нет слов-табу («успей/скидка только сегодня/выгодно»); использован customer language ICP-04.
- [ ] Есть intent-блок после заявки (микро-вопрос + контрольный «кешбэк» + чекбокс).
- [ ] Соблюдены честность-констрейнты (Ozon-only, кешбэк без цифр, «не зарабатываем на продавцах»).
- [ ] Demo показывает и «зелёный», и «красный» пример (нет давления «покупай»).
- [ ] Mobile-first, адаптивно, спокойный тон, без таймеров.
