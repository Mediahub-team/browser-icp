# Лендинг-спека — O11/O12, мотив C (доверие к выплате), waitlist

> Пред-продуктовый тест: продукт НЕ запущен, **никому не платим**. CTA = запись в лист
> ожидания, меряем спрос. Оффер: [[offer-c-trust-gated]]. Угол — **доверие к выплате**, НЕ
> «выгода». **БЕЗ связывающих цифр** (%/порог/срок) — honor-at-launch.
>
> 🎓 **ОБУЧАЮЩАЯ ЯЧЕЙКА. Заявки дисконтируем.** Главное измерение лендинга — **разрыв
> signup↔интент**. CTA «лист ожидания» — дешёвое действие → слабый сигнал; усиливаем
> вторичной инструментовкой интента (ниже).

## Hero (доверие к выплате)
- **H1:** «Кешбэк, который реально выводится — честно, без холда.»
- **Подзаголовок:** «Без "после проверки", без аннулирований "без причины". В этот раз
  кешбэк ты выведешь сам — и поверишь, потому что проверишь.» *(без процента/порога/срока)*
- **Визуал hero:** статусы «Проверяем → Начислено → **Выведено** ✓» (без сумм).
- **Доп. блок для O12 (ICP-06):** мини-калькулятор «сколько теряешь на объёме» (иллюстративный,
  без обещанного %) + плашка S «проверь детское/продавца до заказа».

## 3 буллета
1. **«Обещали процент, а он не упал» — больше нет.** Прозрачные статусы начисления, никаких
   тихих аннулирований.
2. **«Дайте вывести маленькую сумму быстро — тогда поверю».** Первый вывод — своими руками,
   без порога-заложника. *(без конкретных цифр)*
3. **Хватит дарить площадке от лени.** Кешбэк на твоём объёме возвращается тебе — а не
   остаётся у площадки. *(для O12 — + проверка товара/продавца до покупки)*

## CTA (первичный)
- **Кнопка: «Записаться в лист ожидания»** (email).
- Микро-обещание: «Позовём первым, когда откроем вывод» — без дат/цифр.

## 🔑 Усиленный вторичный интент-сигнал (ключ для дисконта «ложных» заявок)
После заявки — короткий шаг, отделяющий «любопытно» от «надо»:
- **Микро-вопрос:** «Что для вас главное?» → выбор: *вывести кешбэк без холода* /
  *проверить товар до покупки* / *сколько теряю на объёме* / *просто посмотреть* —
  дизамбигуация реального мотива (и отлов «зашёл из любопытства»).
- **Чекбокс микро-коммитмента:** ☑ «Готов попробовать первым / оставить отзыв» —
  **ключевой сигнал для дисконта**: заявки без галочки взвешиваем ниже.

## Honor-at-launch дисклеймер
- Мелким, но честно: «Продукт в разработке. Точные условия вывода (процент, порог, сроки)
  объявим на запуске — здесь мы их не фиксируем.» → защищает от обвинений «обещали Х», когда
  продукт может не вытянуть конкретные цифры.

## Что меряем (особенно разрыв signup↔интент)
- **CTR → signup-rate → cost-per-signup.**
- **Качество интента (главное):** доля поставивших чекбокс «готов попробовать первым»;
  распределение ответов микро-вопроса (доля «кешбэк/проверка/объём» vs «просто посмотреть»).
- **🎯 Разрыв signup↔интент:** raw-signup vs **дисконтированный** (заявки × доля
  микро-коммитмента × релевантность ответа) — главный итог обучающей ячейки.
- **Поведение:** scroll-depth, клик по вторичному шагу.
- Сверяем эмоциональный кликбейт («детское/без холда») с микро-вопросом — ловим заявки без fit.
- **Гипотеза:** высокий signup при низком интенте → большой разрыв (калибровка C-оффера).
