# Превью креативов

Посмотреть, как объявления выглядят ДО заливки в Яндекс Директ.

## Поиск (контекст) — своё, готово
`preview_search.py` рендерит мокап поисковой выдачи Яндекса из campaign-spec JSON
(того же формата, что `../build_campaign.py`). Показывает заголовок/доп.заголовок/текст,
быстрые ссылки, уточнения и **счётчики длин полей** под каждым объявлением.

```bash
python3 preview_search.py --spec ../campaign-spec.search.example.json
# → build/preview-search.html (открой в браузере)
```

## РСЯ (баннеры) — свои HTML-шаблоны → PNG
По решению — собственные баннер-шаблоны на бренд-дизайн-системе (см. `../landing/design-system.css`),
рендер в PNG под размеры Яндекса (1080×1080, 1080×607 и стандартные форматы РСЯ) через
headless Chrome. Не «AI-slop», на бренде, A/B-able. *(Строится — на основе бренд-визуала из Figma.)*

> Альтернатива для скорости/охвата — нативный **Яндекс «Конструктор креативов»**
> (TextAdBuilderAd). Внешние AI-баннер-генераторы не используем — дают генерик-вид.
