# Источник лендинга — реальный код бренда

Разбор репозитория **[Mediahub-team/Browserlanding](https://github.com/Mediahub-team/Browserlanding)** —
это боевой исходник лендинга (Figma Make-экспорт). Используем его как **истину по бренду**
вместо реконструкций.

## Стек
React + Vite + Tailwind + shadcn/ui (Radix, MUI), pnpm. Запуск: `pnpm i && pnpm dev`.
- `src/app/App.tsx` — рендерит `Landing1440Light`, по клику CTA открывает `WaitlistModal`.
- `src/imports/Landing1440Light/index.tsx` — сам лендинг (≈2980 строк, абсолютное
  позиционирование Figma Make + реальные PNG-ассеты рядом).
- `src/imports/LandingForm*/` — экраны формы.
- `src/app/components/WaitlistModal.tsx` — модалка заявки.
- Шрифты (`src/styles/fonts.css`): **Manrope** 400/700 (заголовки/body), Inter (форма), Roboto (UI телефона).

## Waitlist-флоу (готовый пред-продуктовый паттерн)
`WaitlistModal`: табы **Email / Телефон** → валидация (email-regex / ≥11 цифр) →
сабмит → `success` («Заявка принята, добавили в список раннего доступа») / `error` + повтор.
Копия оффера: «Ранний доступ … бонус **+200 ₽** на первую покупку».
**⚠️ Сабмит — заглушка** (`setTimeout 800ms`, без бэкенда).
