# Этап 8 — Таргетинг и реклама

Настройка таргета и креативов под офферы и аудитории + план сплит-теста.
- [`targeting/`](targeting/) — таргетинг под **РСЯ** (ведущая площадка) + опц. Поиск-контроль (`<segment>.md`): многоосевой таргетинг (ключи-как-контекст + ручная аудитория: интересы/поведение, сегменты Яндекс.Аудиторий, корректировки). Шаблон: [`../templates/ad-targeting-template.md`](../templates/ad-targeting-template.md).
  - **Ось 2 «Интересы и привычки» — единый профиль пользователя.** Кроме категорий интересов описываем, **где аудитория «живёт»**: посещаемые **сайты** (домены), используемые **приложения**, посещаемые офлайн **организации/категории** (Яндекс.Бизнес). В Директе это один объект «Интересы и привычки» (элементы комбинируются по ИЛИ). Списки — **расширенные**, рядом — оценка охвата (`высокий/средний/низкий`), потому что интерфейс Директа при заведении показывает охват площадки → даём из чего выбрать высокоохватные. Охват **сайтов** моделируем **прокси по поисковой видимости** через MCP `bukvarix` (частотность бренд-/каталог-запросов домена, регион «Россия»), помечаем `~`; охват **приложений/организаций** — экспертная оценка. Это **оценка**, финальный отбор — по фактической цифре в интерфейсе.
- [`creatives/`](creatives/) — креативы под офферы (`<offer>.md`) в **формате РСЯ** (текст+картинка): тексты (Title/Title2/Text), сценарии видео, визуал-бриф. Шаблон: [`../templates/creative-template.md`](../templates/creative-template.md).
- [`landings/`](landings/) — ТЗ на пред-продуктовые лендинги по позиционированию продукта (`landing-<version-name>.md`, 1 на позиционированию продукта). Шаблон: [`../templates/landing-designer-brief.md`](../templates/landing-designer-brief.md).
- [`references/`](references/) — формулировки конкурентов для вдохновения при написании лендинга. Рабочий цикл:
  1. `08-ads/tools/references/add_references.py` — скачивает HTML-снапшоты по `links.json` в `references/*.html` (файлы временные, в `.gitignore`).
  2. `08-ads/tools/references/extract_references.py` — парсит HTML → извлекает H1/H2/CTA/буллеты → сохраняет `references/<domain>.md`; английский текст переводит через Google Translate (без ключа), обе версии — в одном файле; перевод требует правки через скилл `russian-copywriting`.
  3. MD-файлы коммитятся; HTML регенерируются при необходимости.
- `test-plan.md` — матрица тестов: оффер × аудитория × креатив × лендинг × площадка, бюджеты, метрики, пороги.

**Площадки (RU):** ведущая — **Яндекс Директ / РСЯ** (текст+картинка, ручная настройка аудитории); Поиск Директа — альтернативная платформа (контрольная кампания на ключах). VK Ads / Telegram Ads — по совпадению с каналами ICP (вторично).
**Вход:** офферы (`07-offers/`). **Выход:** запущенные кампании + зафиксированные гипотезы.

### Инструменты и форматы (корневое)
- [`tools/`](tools/) — Python-инструменты: **Yandex Direct API** (запуск кампаний, см. `tools/README.md`) и **references** (`add_references.py` + `extract_references.py` — загрузка и разбор референсов).
- Шаблон лендинга: [`../templates/landing-designer-brief.md`](../templates/landing-designer-brief.md) (ТЗ для дизайнера; содержит инструкцию по использованию `references/`).

### Принцип теста
Изолируем переменные: один оффер гоняем на несколько аудиторий и несколько офферов на
одну аудиторию, чтобы развести вклад «оффер» и «аудитория». На РСЯ дополнительно разводим
**оси таргетинга по группам** (ключи-как-контекст / интересы-поведение / сегменты Аудиторий),
чтобы прочитать вклад каждой оси. Перед запуском фиксируем ожидания, чтобы на этапе 9
честно сверить факт с гипотезой.

### Скиллы этапа (обязательный шаг)
Каждый артефакт проходит через профильный скилл. Правило: **скилл предлагает — гейт решает.**
Скиллы несут US-приор (Google/Meta/LinkedIn, «максимизируй конверсию») — **адаптируем под RU**
(площадки VK/Директ/TG, char-лимиты, метрики CPS/waitlist+AppMetrica) и пропускаем через
**промис-гейт** (без связывающих цифр/сверх инвариантов [[product-functionality]] §2, без killed-механики, ФЗ-38).

| Артефакт | Обязательные скиллы | RU-адаптация |
|---|---|---|
| `targeting/<segment>.md` | `ads` + `russian-copywriting` (тексты-посылы) | Google/Meta-логика → **РСЯ-таргетинги Директа**: ключи-как-контекст + ручная аудитория (`AudienceTargets` интересы/поведение, сегменты Яндекс.Аудиторий, `BidModifiers`); оси разнесены по группам. Поиск — альтернативная платформа |
| `creatives/<offer>.md` (копия) | `ad-creative` + `russian-copywriting` | RSA-структура → char-лимиты Директа (**Title 56 / Title2 30 / Text 81**), формат РСЯ текст+картинка; язык — живой русский |
| `creatives/` (визуал/видео) | `image`, `video` | форматы и спеки **РСЯ** (картинка-носитель: 300×600/240×400/300×250/300×300, текст ≤20%, `AdImages`); текст на макете — по-русски, бренд-токены |
| `landings/landing-<version-name>.md` (ТЗ) | `russian-copywriting` | копия страницы — живой русский «ты/вы», по ФЗ-38; структура — из шаблона |
| `test-plan.md` | `ab-testing` | пороги/значимость → метрики RU-пред-запуска (CPS, заявки), сверка с этапом 9 |

> 🚫 **Не пробрасывать формулировки из предыдущих артефактов.** Из оффера/ICP берём факты,
> ограничения и customer language (голоса клиента — в кавычках, как сырьё); продающие фразы
> пишем **заново** через `russian-copywriting`. Дословный перенос заголовков/посылов вниз запрещён
> (анти-циркулярность языка).
