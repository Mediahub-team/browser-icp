# Сбор ключевых слов — ICP-04 privacy/анти-Яндекс (Яндекс Директ)

> Сырой сбор фраз через MCP `bukvarix` + анализ + курированные группы. На него ссылается
> [targeting-icp-04](../targeting/targeting-icp-04.md). Ключи — данные, орфографию не правим.

## 0. Привязка
- **ICP:** [icp-04-privacy-antiyandex](../../02-icp/icp-04-privacy-antiyandex.md) · **Мотив:** контроль/приватность.
- **Инструмент:** MCP `bukvarix` (batch).

## 1. Seed-фразы
- `приватный браузер` — ядро (браузер без слежки)
- `браузер без слежки` — мотив приватности
- `нейросеть без впн` — доступ без VPN
- `ии без яндекса` — анти-экосистема (гипотеза)
- `нейросеть на русском` — русскоязычный ИИ
- **Exclusions:** `озвучка`, `android` (мы iOS), `firefox`

## 2. Выдача и анализ (Bukvarix, частотность «весь мир», broad)
| Фраза | Широкая частотность | Решение |
|---|---|---|
| приватный браузер | 1650 | ядро |
| браузер приватный | 1624 | ядро |

- **Коррекция формы:** рынок ищет «приватный браузер» (не «приватность-браузер»); «нейросеть без впн» — устойчивая форма.
- **Head vs long-tail:** «нейросеть на русском» — гигантский, но не про приватность/анти-Яндекс → не ядро интента icp-04.
- **Off-intent в минус:** `андроид`, `firefox`, `озвучка`.

## 3. Курированные группы (в таргет)
- **Группа A — приватный браузер:** `приватный браузер` 1650 · `браузер приватный` 1624 · `браузер без слежки` 203 · `самый приватный браузер` 112
- **Группа B — ИИ без барьеров:** `нейросеть без впн` 1019 · `нейросеть на русском` 190280 (узкий матч + минусовка)
- **Минус-слова:** `андроид`, `firefox`, `chrome`, `озвучка`, `скачать музыку`, `vpn скачать`

## 4. Находки для стратегии
- **Охват (KC/размер ниши):** прямой анти-Яндекс-интент в поиске **почти отсутствует** («ии без яндекса» не набрал объёма) → подтверждает риск малой ниши ([[icp-04-privacy-antiyandex]] §10). **Вывод: для icp-04 ключи слабы — ведущая ось таргета не поиск/ключи, а интересы/сегменты (Ось 2/3) и Telegram-каналы про приватность.**
- **Сигнал для креатива:** лексика «приватный», «без слежки», «без впн» — реальные слова рынка (отзеркалить, писать заново через гейт).
