## 0. Привязка
- **ICP / аудитория:** [icp-02-web-native-mp](../../02-icp/icp-02-web-native-mp.md) · **Ведущий мотив:** комфорт привычного web-канала + лёгкая экономия.
- **Инструмент:** MCP `bukvarix` (`bukvarix_search_keywords_batch`, один батч 20 seed + 12 exclusions, `num=300`).

## 1. Seed-фразы (гипотезы запросов)
> Из ICP §6 («куплю с компа», «не хочу ставить их приложение», «убедиться в продавце») и §7 (Яндекс-поиск по товарам/сайтам, старшая аудитория).
- `озон сайт`, `вайлдберриз сайт`, `официальный сайт озон/вайлдберриз` — навигация на сайт МП (web-нативное поведение, ядро K0).
- `купить через браузер`, `купить с компьютера` — канальное намерение (но `купить с компьютера` → тянет «купить компьютер», минус).
- `кэшбэк за покупки`, `кэшбэк на сайте`, `кэшбэк без приложения` — связка кэшбэк × web-канал.
- `проверить продавца`, `отзывы о продавце`, `рейтинг продавца`, `надежный продавец озон` — глубина проверки на крупном чеке (общая с [[offer-04-seller-check]]).
- `кэшбэк сервис`, `кэшбэк с покупок` — класс инструмента.
- **Exclusions для сбора:** работа/вакансии/франшиза/опт (продавец-сторона), пункт выдачи/доставка курьером, скачать бесплатно/взлом, порно/казино/ставки.

- **Коррекция орфографии/формы:** «кэшбэк» через «э». Seed `купить с компьютера` дал ложный кластер `купить компьютер` (241k) — режется словом `компьютер` в минусах.
- **Head vs long-tail:** объём несут навигационные `<МП> сайт` / `официальный сайт <МП>` (сотни тысяч) — это и есть сигнал «покупаю через сайт». Связку с продуктом дают `кэшбэк за покупки`, `проверить продавца`.

## 4. Находки для стратегии
- **Гипотеза по охвату:** навигационный интент «<МП> сайт» — огромный (сотни тысяч), подтверждает существование web-нативной базы (K0). Но это **навигация на сайт МП**, не намерение «сменить браузер» — на этапе 9 проверяем, конвертируется ли широкий контекст в клик «скачать» (узкое горло; сильнейший конкурент — Яндекс Браузер, ICP §8).
- **Сигнал для креатива:** язык — «куплю с компа», «на сайте», «без приложения», «убедиться в продавце». Отзеркаливаем заново через `russian-copywriting`.
