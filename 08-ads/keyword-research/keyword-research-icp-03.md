# Сбор ключевых слов — ICP-03 знаниевые работники (Яндекс Директ)

> На него ссылается [targeting-icp-03](../targeting/targeting-icp-03.md). Ключи — данные, форму сохраняем.

## 0. Привязка
- **ICP:** [icp-03-knowledge-workers](../../02-icp/icp-03-knowledge-workers.md) · **Мотив:** контроль информации / уверенность в выводе.
- **Инструмент:** MCP `bukvarix` (batch).

## 1. Seed-фразы
- `ии для работы с текстом` — рабочий ресёрч
- `краткое содержание текста ии` / `нейросеть суммаризация` — сведение/пересказ
- `пересказ статьи нейросеть` — пересказ источника
- **Exclusions:** `учеба`, `школа`, `реферат` (это icp-01)

## 2. Выдача и анализ (Bukvarix, broad)
| Фраза | Широкая частотность | Решение |
|---|---|---|
| ии работа с текстом | 1171 | ядро |
| ии для работы с текстом | 539 | ядро |
| ии для работы с текстами | 579 | ядро |
| ии работа с текстом бесплатно | 153 | точное |
| ии краткое содержание текста | 60 | точное |
| пересказ статьи нейросеть | 105 | точное |
| ии по работе с текстом | 111 | точное |

- **Head vs long-tail:** «ии работа с текстом» — основной объём; «суммаризация/пересказ» — нишевые точные.
- **Природа боли (этап 6):** запросов прямо про «свести вкладки» в поиске нет → multi-tab не ищут словами → как у icp-04, ведущая ось — интересы/сегменты, ключи поддерживают.

## 3. Курированные группы (в таргет)
- **Группа A — работа с текстом:** `ии работа с текстом` 1171 · `ии для работы с текстом` 539 · `ии для работы с текстами` 579
- **Группа B — пересказ/суть:** `ии краткое содержание текста` 60 · `пересказ статьи нейросеть` 105
- **Минус-слова:** `учеба`, `школа`, `реферат`, `курсовая`, `озвучка`, `генерация картинок`

## 4. Находки для стратегии
- **Охват:** интент «работа с текстом» умеренный; сведения вкладок словами не ищут → таргет на деловые/аналитические интересы и Telegram-каналы.
- **Сигнал для креатива:** «работа с текстом», «краткое содержание», «со ссылками» — лексика для отзеркаливания.
