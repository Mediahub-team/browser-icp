# Сбор ключевых слов — ICP-02 контент-специалисты (Яндекс Директ)

> На него ссылается [targeting-icp-02](../targeting/targeting-icp-02.md). Ключи — данные, форму сохраняем.

## 0. Привязка
- **ICP:** [icp-02-content-pros](../../02-icp/icp-02-content-pros.md) · **Мотив:** скорость / поток работы.
- **Инструмент:** MCP `bukvarix` (batch).

## 1. Seed-фразы
- `нейросеть для текста` / `ии для копирайтера` — рабочий инструмент
- `чат gpt без впн` — доступ без VPN (их боль)
- `нейросеть на русском` — доступный ИИ
- **Exclusions:** `учеба`, `реферат`, `озвучка`, `картинки`

## 2. Выдача и анализ (Bukvarix, broad)
| Фраза | Широкая частотность | Решение |
|---|---|---|
| ии работа с текстом | 1171 | ядро |
| нейросеть без впн | 1019 | ядро (доступ) |
| нейросеть на русском | 190 280 | широкое (узкий матч + минусовка) |
| русские нейросети | 213 873 | широкое (шумно) |
| ии для работы с текстом | 539 | точное |

- **Head vs long-tail:** «нейросеть на русском/русские нейросети» — огромный, но крайне широкий интент; для контент-про брать узким соответствием + сильная минусовка.
- **Боль копирования (этап 6, подтверждена):** прямого запроса «чтобы не копировать в чат» нет → ловим через рабочий инструмент + «без впн».

## 3. Курированные группы (в таргет)
- **Группа A — рабочий ИИ для текста:** `ии работа с текстом` 1171 · `ии для работы с текстом` 539
- **Группа B — доступ без барьеров:** `нейросеть без впн` 1019 · `нейросеть на русском` 190280 (узкий матч)
- **Минус-слова:** `учеба`, `реферат`, `курсовая`, `озвучка`, `картинк`, `рисует`, `музык`

## 4. Находки для стратегии
- **Охват:** «без впн» + «работа с текстом» — рабочий объём; широкие «русские нейросети» дают охват, но шум.
- **Сигнал для креатива:** «без впн», «прямо на странице», «со ссылками» — отзеркалить.
