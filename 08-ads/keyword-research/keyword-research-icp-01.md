# Сбор ключевых слов — ICP-01 студенты (Яндекс Директ)

> Резервный сегмент (замер охвата, [[comparison-2026-06-23]] §5). На него ссылается
> [targeting-icp-01](../targeting/targeting-icp-01.md). Ключи — данные, форму сохраняем.

## 0. Привязка
- **ICP:** [icp-01-students](../../02-icp/icp-01-students.md) · **Мотив:** «быстро понять» / экономия времени.
- **Инструмент:** MCP `bukvarix` (batch).

## 1. Seed-фразы
- `нейросеть для учебы` — ядро
- `пересказ статьи нейросеть` / `ии краткое содержание текста` — пересказ
- `бесплатная нейросеть для учебы` — бесплатность критична
- **Exclusions:** `порно`, `озвучка`, `по фото`, `решебник`

## 2. Выдача и анализ (Bukvarix, broad)
| Фраза | Широкая частотность | Решение |
|---|---|---|
| нейросеть для учебы / нейросети для учебы | 2864 | ядро |
| нейросети учеба | 3329 | ядро |
| бесплатная нейросеть для учебы | 691 | ядро (бесплатность) |
| лучшие нейросети для учебы | 467 | точное |
| нейросеть помощь в учебе | 155 | точное |
| пересказ статьи нейросеть | 105 | точное |
| нейросеть для учебы по фото | 18 | минус (не наш сценарий) |

- **Head vs long-tail:** «нейросеть для учёбы» (+ «бесплатно») — основной объём, чистый интент.
- **Бесплатность** — частый модификатор → подтверждает ценовую чувствительность ([[icp-01-students]] §1).

## 3. Курированные группы (в таргет)
- **Группа A — ИИ для учёбы:** `нейросеть для учебы` 2864 · `нейросети учеба` 3329 · `бесплатная нейросеть для учебы` 691
- **Группа B — пересказ/суть:** `пересказ статьи нейросеть` 105 · `ии краткое содержание текста` 60
- **Минус-слова:** `по фото`, `решебник`, `гдз`, `порно`, `озвучка`, `картинк`

## 4. Находки для стратегии
- **Охват:** чистый и заметный интент «нейросеть для учёбы» → хороший reach для замера T5.
- **Сигнал для креатива:** «бесплатно», «перескажет», «понять быстро» — отзеркалить.
