# Креатив — offer-03-no-ritual / ICP-03 (Telegram/Директ · видео + карусель)

**Источники:** [[offer-03-no-ritual]] · [[icp-03-cashback-optimizers]] · [[comparison-2026-06-10]].

> 🛠 `ad-creative` + `russian-copywriting` («ты», по ФЗ-38, через гейт); визуал/видео — `image`/`video`.
> 🚫 Фразы оффера не переброшены: «ловит сам», «без ритуала», «покупай как обычно», «стек поверх банка»
> заменены свежими. Из ICP взяты факты и голоса клиента (в кавычках) как сырьё, копия написана заново.

## 0. Привязка
- **Оффер:** [[offer-03-no-ritual]] · **ICP / аудитория:** [[icp-03-cashback-optimizers]]
- **Площадка:** Telegram (посевы/Ads) + Яндекс Директ (РСЯ)
- **Формат:** видео 9:16 (6–12 с) + карусель (запасной)
- **Боль/триггер (этап 6):** сверять выгоду перед каждой покупкой · **угол:** кешбэк со всех покупок, без проверок
- **Главная метрика:** CTR · CPC → CPS (заявка в waitlist), см. [[test-plan]]

## 1. Сообщение (ядро)
- **Главный посыл:** «Кешбэк со всех покупок, а не только у партнёров — браузер сам замечает оплату.»
- **RTB / доказательство:** возвращается с обычных магазинов, не из короткого списка; складывается с тем, что уже даёт банк; статус начисления виден (доверие — в связке с [[creative-03-payout-proof]]).
- **CTA:** «Записаться в лист ожидания» *(пред-запуск, не «скачать»)*.
- **Голоса клиента как сырьё (в кавычках, не слоган):** «надоело заходить через ссылку», «дайте пруф вывода», «без танцев с бубном». · **Слова-табу:** «халява», «заработок», гарантии мгновенного вывода, конкретные % до фиксации сетки.

## 2. Заголовки для A/B (свежие, скилл `russian-copywriting`)
1. «Перестань выгадывать, где сегодня кешбэк» — *проверяет: усталость от сверки как хук.*
2. «Возвращается с любого магазина, не из списка» — *проверяет: покрытие «любой сайт» как тяга.*
3. «К банковскому кешбэку — ещё один, сверху» — *проверяет снятие «у меня уже есть».*

## 3. Бриф по формату
**Видео (9:16, 6–12 с).** Хук 0–2 с: человек перед оплатой open-open-open вкладки агрегаторов, сверяет, где сегодня выгоднее (узнаваемо). 3–7 с: «А можно не сверять» → экран браузера, рубли падают на баланс на обычной покупке. 8–12 с: CTA-кадр «Записаться в лист ожидания». Субтитры обязательны (85% смотрят без звука), первые 3 с решают досмотр. Без фейк-сумм.
**Карусель (запас).** Слайд 1: «Сверять выгоду перед каждой покупкой — надоедает» · 2: «Возвращается само, с любого магазина» · 3: «Поверх банковского кешбэка» · 4: CTA waitlist.

## 4. Визуальный бриф (→ скилл `image`/`video`)
- Палитра — **бренд-токены** (индиго-синий первичный + зелёный акцент, светлый фон, Golos Text — `08-ads/tools/landing/design-system.css`). Настроение: «стало проще».
- Показываем **честно**: бейдж кешбэка на обычной покупке (без конкретной суммы); выплат, которых нет, не рисуем; лицо реальное, не сток.
- Mobile-first: крупный читаемый оверлей, текст ≤ 20% площади, контраст AA.

## 5. Соответствие и ограничения (гейт)
- Без связывающих цифр (%/сумма/срок), без давления/таймеров, без «лучший/№1» (ФЗ-38); модерация Telegram/Директ.
- Ничего против инвариантов ([[product-functionality]] §2); не воскрешать killed-механику.

## 6. Гипотеза и измерение
- Проверяет: хук «надоело сверять» → клик; ожидаем высокий CTR в кешбэк-каналах, конверсию в заявку гейтит K3 (связка с payout-proof). Сверка — этап 9.
