# Креатив — «Ловит сам, без ритуала» (ICP-03)

**Источники:** [[offer-03-no-ritual]] · [[icp-03-cashback-optimizers]] §6 · [[comparison-2026-06-10]] §6.

> ТЗ на рекламный креатив под оффер. Один файл = один оффер × ICP. Описание **общее, без привязки к
> платформе**. Ведущий угол — **«ловит сам, без ритуала»** (ценность первичного сегмента).
>
> ⚠️ **Честность (K3).** Без связывающих цифр (%/сумма/срок); без обещаний против инвариантов
> [[product-functionality]] §2 (кэшбэк только через браузер); killed-механику не воскрешаем.
> 🔑 Лексика отзеркалена из Bukvarix ([keyword-research](../keyword-research/keyword-research-icp-03-cashback-optimizers.md)): «лучший/максимальный/повышенный», «со всех сайтов». Форма — «кэшбэк». Продающие фразы написаны заново через `russian-copywriting` (обращение на «ты», аудитория молодая/соцсети).

## 0. Привязка
- **Оффер:** `07-offers/offer-03-no-ritual` · **ICP / аудитория:** `02-icp/icp-03-cashback-optimizers`
- **Боль/триггер (этап 6, тема ×4):** ритуал — заходить через спец-ссылку, проверять категорию, помнить промокод. · **Ведущий рычаг/угол:** «ловит сам за любой сайт, без ритуала».
- **Главная метрика:** CPC + стоимость целевого действия (клик «скачать» → действие на лендинге); CTR — диагностика.

## 1. Сообщение (ядро, едино для всех углов)
- **Главный посыл (языком клиента):** «Покупай как обычно — кэшбэк ловится сам, за любой сайт, без захода через ссылки.»
- **RTB / доказательство:** один браузер вместо зоопарка сервисов; авто-фиксация покупки без партнёрской ссылки; кэшбэк стеком поверх банка (модель переменная — числа не называем).
- **CTA:** прямое **«скачать»**. Лендинг по клику честно раскрывает пред-продукт (извинение) и фиксирует спрос — разведка спроса, не обман.
- **Слова-маркеры:** «ловит сам», «без ритуала», «за любой сайт», «без захода через ссылки», «стек поверх банка». · **Слова-табу (ICP §6):** размытые «выгодные предложения» без сути; обещания мгновенного вывода; конкретные неподтверждённые %/суммы; «лучший/№1/гарантированно» (ФЗ-38).

## 2. Углы и формулировки (A/B/C тест)
> 3 угла — разные акценты одного оффера. Внутри угла — по 3 заголовка и 3 подписи (заготовки для
> дизайнера: выбрать по одной на угол). Заголовок ≤56, подпись ≤81. Фактическая длина в скобках.

**Угол A — «покупай как обычно, ловит сам»** — проверяет: цепляет ли сама механика авто-кэшбэка без действий.
- Заголовки (≤56): 1) «Покупай как обычно — кэшбэк ловится сам» (39) 2) «Кэшбэк за любой сайт, без захода через ссылки» (45) 3) «Один браузер вместо пяти кэшбэк-сервисов» (40)
- Подписи (≤81): 1) «Поставь браузер — проверь на следующей покупке, ссылки не нужны.» (64) 2) «Не нужно искать спец-ссылку агрегатора. Открыл сайт — кэшбэк уже считается.» (75) 3) «Покупаешь где обычно, кэшбэк ловится в фоне. Скачай и проверь сам.» (66)

**Угол B — «хватит ритуала»** — проверяет: бьёт ли прямое называние боли (заход через ссылку) сильнее, чем механика.
- Заголовки (≤56): 1) «Хватит жонглировать кэшбэк-сервисами» (36) 2) «Надоело заходить через ссылку? Ловит сам» (40) 3) «Кэшбэк сам, без ритуала и спец-ссылок» (37)
- Подписи (≤81): 1) «Backit, категория банка, промокод — собери в одном браузере. Скачай.» (68) 2) «Каждую покупку прогонять через сервисы устаёшь. Браузер делает это сам.» (71) 3) «Никаких заходов через ссылку перед покупкой. Скачай и забудь про ритуал.» (72)

**Угол C — «стек поверх банка»** — проверяет: заходит ли «не вместо, а сверху» (снимает страх «ещё один слой ради того же»).
- Заголовки (≤56): 1) «Твой стек кэшбэка — и сверху ещё процент» (40) 2) «Кэшбэк поверх банка, за любой сайт» (34) 3) «Ставишь раз — кэшбэк со всех сайтов сам» (39)
- Подписи (≤81): 1) «Не вместо банка, а сверху: кэшбэк ещё и за сайты без партнёрки. Скачай.» (71) 2) «Банк платит за категории, браузер ловит остальное. Поставь и сравни.» (68) 3) «Настроил один раз — дальше браузер сам цепляет кэшбэк. Скачай браузер.» (70)

## 3. Визуал (главный носитель — изображение)
> Подробное описание изображения, 3 вариации с разным характером (дизайнер выбирает). Видео и карусель — опции под угол-победитель.

**Изображение — 3 вариации (разный характер):**
- **Вариация 1 — спокойная-бытовая:** человек оформляет обычную покупку в браузере на ноутбуке, в углу окна — ненавязчивый бейдж «кэшбэк засчитан» без суммы. Фокус на лёгкости: никаких вкладок агрегаторов. Палитра — бренд-токены, спокойная. Оверлей-заголовок крупно, mobile-читаемо. Честно: реальный интерфейс браузера, без фейк-сумм.
- **Вариация 2 — ироничная «до/после»:** слева — хаос из открытых вкладок Backit/Megabonus/банка/блокнота с промокодами и подпись «раньше»; справа — одно чистое окно браузера, «теперь». Тон с юмором над ритуалом. Контраст AA, текст ≤20%.
- **Вариация 3 — строго-функциональная:** схема-стрелка «5 сервисов → 1 браузер», минимум декора, акцент на «единое правило вместо зоопарка». Для аудитории, которая считает и любит ясность. Без сумм/процентов.
- **Общие требования:** реальный продукт/прототип, не AI-интерфейс; без мелкого нечитаемого текста; контраст AA; текст ≤20% площади; никаких фейк-балансов и несуществующих цифр.

**Видео (опция).** 6–15 с, хук в первые 2–3 сек («снова заходишь через ссылку?»); биты: ритуал-боль → один браузер → бейдж «ловит сам» → CTA-кадр «скачать». Субтитры (звук выключен).
**Карусель (опция).** Слайды: 1) «5 сервисов на каждую покупку» → 2) «промокод, ссылка, категория — каждый раз» → 3) «один браузер ловит сам» → 4) CTA «скачать».

## 4. Соответствие и ограничения (гейт)
- Честность-констрейнты (см. шапку); без давления/таймеров/«осталось N мест»; без «лучший/№1/гарантированно/100 %» (ФЗ-38). Слово «лучший» — только как лексика поиска в таргете, **не** в тексте объявления.
- **CTA «скачать» честен через лендинг:** объявление зовёт скачать, лендинг сразу раскрывает пред-продукт (извинение) и фиксирует спрос; в объявлении не обещаем готовый продукт сверх «скачать».
- Маркировка (erid/ОРД) — на уровне размещения.

## 5. Гипотеза и измерение
- **A** — заходит ли «ловит сам» как механика (ожидаем высокий CTR на Core-оптимизаторах). **B** — сильнее ли прямое называние боли «ритуал». **C** — снимает ли «стек поверх банка» возражение «ещё один слой» (риск K2). Сигнал — стоимость целевого действия по углу для честной сверки на этапе 9.
