# Креатив — offer-03-no-ritual / ICP-03 (Telegram + Директ РСЯ · видео + карусель)

**Источники:** [[offer-03-no-ritual]] · [[icp-03-cashback-optimizers]] · [[comparison-2026-06-10]].

> 🛠 **Скиллы:** `ad-creative` (структура и масштаб вариантов, RU-лимиты Директа 56/30/81, TG ≤160)
> + `russian-copywriting` (живой русский «ты», без канцелярита, ФЗ-38); визуал — `image`.
> 🚫 **Формулировки не переброшены.** Слоганы оффера («ловит сам, без ритуала», «Хватит жонглировать
> сервисами», «Один браузер вместо пяти кешбэк-сервисов») **переписаны заново**. Из ICP/оффера взяты
> факты и голоса клиента (в кавычках) как сырьё. Обращение — «ты».

## 0. Привязка
- **Оффер:** [[offer-03-no-ritual]] · **ICP / аудитория:** [[icp-03-cashback-optimizers]]
- **Площадка:** Telegram (Ads + посевы в кешбэк/скидочных каналах) + Яндекс Директ (РСЯ)
- **Формат:** видео 9:16 (6–12 с, «ритуал перед покупкой → браузер делает сам») + карусель (запас)
- **Боль/триггер (этап 6):** ритуал — зайти через ссылку, проверить категорию, вспомнить промокод перед каждой покупкой · **угол:** возврат считается сам, без отдельных действий
- **Главная метрика:** CTR (ждём высокий в кешбэк-каналах) → CPS (заявка в waitlist), см. [[test-plan]]

## 1. Сообщение (ядро, едино для всех вариантов)
- **Главный посыл (языком клиента):** «Браузер сам замечает покупку и считает возврат — открывать сервис
  и искать ссылку не нужно.»
- **RTB / доказательство:** возврат за покупки через браузер начисляется без захода через партнёрскую
  ссылку; работает на любом сайте, не только у партнёров; видно статус начисления (доверие стекуется с [[offer-03-payout-proof]]); «по публичной оферте».
- **CTA:** «Записаться в лист ожидания» *(пред-запуск, не «скачать приложение»)*.
- **Слова-маркеры (звучат):** само, без ссылок, любой сайт, поверх банка.
- **Слова-табу (НЕ употреблять):** «халява», «заработок», «лёгкие деньги»; точные суммы / проценты /
  сроки кешбэка; «лучший / №1 / гарантированно / 100 %» (ФЗ-38).
- **Голоса клиента как сырьё (в кавычках, не слоган):** «надоело заходить через ссылку каждый раз»,
  «у меня уже связка — чем ты лучше», «пруф вывода покажи».

## 2. Заголовки для A/B (свежие, скилл `russian-copywriting`)
> RU-лимиты: Директ Заголовок-1 ≤56, Заголовок-2 ≤30, Текст ≤81; Telegram ≤160. Символы посчитаны.

### Угол A — рутина перед каждой покупкой
- **Директ Заголовок-1:** «Возврат считается без лишних шагов перед покупкой» (49) — *проверяет: боль ритуала как хук.*
- **Директ Заголовок-2:** «Ничего не настраиваешь» (22)
- **Директ Текст:** «Не надо открывать сервис и искать ссылку — браузер замечает покупку сам» (71)
- **Telegram:** «Перед каждой покупкой открываешь кешбэк-сервис и ищешь ссылку? Браузер замечает оплату сам, на любом сайте. Запишись в лист ожидания» (135)

### Угол B — зоопарк инструментов → один
- **Директ Заголовок-1:** «Кешбэк за любой сайт в одном месте» (34) — *проверяет: усталость от связки из нескольких сервисов.*
- **Директ Заголовок-2:** «Без пяти вкладок» (16)
- **Директ Текст:** «Не нужно держать три сервиса и помнить, где какой процент» (57)
- **Telegram:** «Три сервиса, промокоды, категория месяца — и всё равно половина покупок мимо. Один браузер видит оплату на любом сайте. Запишись в лист ожидания» (146)

### Угол C — стек поверх банка
- **Директ Заголовок-1:** «Возврат поверх банковского кешбэка» (34) — *проверяет: тягу «добавить, не меняя банк».*
- **Директ Заголовок-2:** «Не вместо, а сверху» (19)
- **Директ Текст:** «Банк своё, а тут — ещё возврат за покупки на сайтах, где его не было» (68)
- **Telegram:** «Банковский кешбэк остаётся, а сверху — возврат за покупки на сайтах, где его раньше не было. За любой сайт через браузер. Запишись в лист ожидания» (150)

## 3. Бриф по формату
**Видео (9:16, 6–12 с).** Хук 0–2 с: рука быстро открывает несколько вкладок/приложений кешбэка перед
оплатой (узнаваемая рутина). 3–7 с: «А это можно не делать» → один экран браузера, на обычной покупке
рядом с суммой появляется бейдж возврата (без числа). 8–12 с: кадр CTA «Записаться в лист ожидания».
Субтитры обязательны (смотрят без звука), первые 3 секунды решают досмотр. Без сумм/процентов нашего возврата.
**Карусель (запас).** Слайд 1: знакомый ритуал (сервис + промокод + категория). 2: один экран браузера,
возврат начисляется сам. 3: «за любой сайт, поверх банка». 4: CTA waitlist. Короткий текст на слайде, без жаргона.

## 4. Визуальный бриф (скилл `image`)
- Палитра — **бренд-токены** (индиго-синий первичный + зелёный акцент, светлый фон, Golos Text,
  `08-ads/tools/landing/design-system.css`). Настроение: «стало просто, без возни».
- Показываем **честно**: бейдж возврата на реальной покупке в браузере, без суммы; интерфейс — скриншот
  прототипа, не AI-генерация экрана; чужих выплат и фейк-балансов не рисуем.
- Mobile-first; текст ≤20 % площади, контраст AA. Избегать: стоковых улыбок, золотых монет и «дождя из
  денег», фиолетовых градиентов-клише, мелкого нечитаемого текста.

## 5. Соответствие и ограничения (гейт)
- Без связывающих цифр (% / сумма / срок), без давления и таймеров, без «лучший / №1 / гарантированно /
  100 %» (ФЗ-38); правила модерации Telegram / Директ; платное размещение — маркировка и erid (в ТЗ, не в хедлайне).
- Ничего против инвариантов [[product-functionality]] §2: возврат только за покупки через браузер; killed-механику не воскрешаем.
- Честный пред-продукт: зовём в лист ожидания, не показываем чужие выплаты.

## 6. Гипотеза и измерение
- Проверяет: какой угол тянет клик — рутина (A), зоопарк сервисов (B) или стек поверх банка (C). Ждём
  высокий CTR в кешбэк-каналах, но конверсию в заявку гейтит K3 → связка с [[creative-03-payout-proof]]
  (T2). Изоляция T1↔T2 по офферу. Кросс X1 — этот угол на ICP-01 (ждём слабее). Сверка — этап 9.
