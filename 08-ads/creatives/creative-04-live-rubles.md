# Креатив — offer-04-live-rubles / ICP-04 (VK/OK · видео-контраст)

**Источники:** [[offer-04-live-rubles]] · [[icp-04-points-stuck]] · [[market-landscape]] §6.

## 0. Привязка
- **Оффер:** [[offer-04-live-rubles]] · **ICP / аудитория:** [[icp-04-points-stuck]]
- **Площадка:** VK Ads / Одноклассники + Яндекс Директ (Поиск)
- **Формат:** видео 1:1/9:16 (контраст «баллы → рубли») + статика
- **Боль/триггер:** баллы сгорают / «не деньги» · **угол:** живые рубли вместо баллов
- **Главная метрика:** CTR (ожидается высокий на эмоции) → CPS

## 1. Сообщение (ядро)
- **Главный посыл:** «Живые рубли на карту — а не баллы, которые сгорают.»
- **RTB / доказательство:** возврат настоящими рублями, можно вывести; ничего не сгорает и не заперто в экосистеме; пруфы (стек с payout-proof); «по оферте».
- **CTA:** «Записаться в лист ожидания».
- **Слова-маркеры:** «живые рубли», «на карту», «не сгорает», «можно вывести». · **Слова-табу:** «баллы», «бонусы», «спасибо» (в нашем возврате — будят боль); точные суммы/сроки.

## 2. Заголовки для A/B
1. «Спасибо опять сгорели? Получай живые рубли на карту.» — проверяет: эмоция сгорания как хук.
2. «Не баллы в экосистеме — рубли, которые можно вывести.» — проверяет: «вывести» как ключевую выгоду.
3. «Кешбэк, который не сгорает.» — проверяет: страх потери (loss-aversion).

## 3. Бриф по формату
**Видео (контраст, 8–12 с).** Хук 0–2 с: уведомление «ваши N бонусов сгорели» (узнаваемо, без бренда банка). 3–7 с: «Получай живые рубли — на карту, не сгорают» → купюры/баланс на карте. 8–12 с: CTA waitlist. Субтитры; без конкретных сумм нашего кешбэка.
**Статика (VK/OK).** Лево «баллы с таймером сгорания» → право «рубли на карте». Простой крупный текст для старшей аудитории.

## 4. Визуальный бриф
- Бренд-токены; настроение «справедливость/облегчение». Крупная типографика (аудитория 30–60).
- **Честно:** показываем форму выплаты (рубли на карту-партнёр) как механику; не рисуем конкретных сумм возврата.
- Mobile-first, высокий контраст (старшая аудитория).

## 5. Соответствие и ограничения
- Не называть бренд банка напрямую (риск модерации/товарных знаков) — обобщённо «баллы, которые сгорают».
- Без связывающих цифр; без давления. Модерация VK/OK/Директ.

## 6. Гипотеза и измерение
- Проверяет: эмоциональный отклик «живые рубли» → CTR. Ожидаем высокий CTR, но узкий охват и риск gate (часть в приложении). Кросс X2 — тот же оффер на ICP-01 (пересечение). Сверка — этап 9.
