# Креатив — offer-04-no-tracking (ICP-04 privacy)

> ТЗ на креатив РСЯ. Обращение — **«ты»**. Единственный креатив icp-04 — акцент на доказательстве приватности (вариант «без Яндекса» снят: бренд в рекламе + дублирование).

## 0. Привязка
- **Оффер:** ИИ, который не профилирует · **Кому:** те, кто ушёл от больших экосистем-трекеров.
- **Главная мысль:** польза ИИ без платы своими данными.
- **Что измеряем:** клики «скачать» + заявки.

## 1. Сообщение
- **Главная мысль:** «ИИ помогает — и не следит за тобой».
- **Почему верить:** запросы не уходят в рекламный профиль; ответы со ссылками; открытая политика данных.
- **Призыв:** «скачать».
- **Должны звучать:** «не следит», «приватно», «твои запросы», «со ссылками».
- **Не должно быть:** суммы, проценты, кешбэк, «лучший/№1».

## 2. Тексты объявлений (A/B/C)

**Угол A — не профилирует**
- Title (≤56): 1) «ИИ, который не следит за тобой» 2) «Помощник без слежки» 3) «ИИ без профиля и трекинга»
- Title2 (≤30): 1) «Запросы остаются твоими» 2) «Без рекламного профиля» 3) «Приватно по умолчанию»
- Text (≤81): 1) «ИИ отвечает по странице и не собирает твои запросы.» 2) «Помощь с любой страницей без слежки и профиля.» 3) «Спроси по странице — данные останутся при тебе.»

**Угол B — твои данные не товар**
- Title (≤56): 1) «Твои запросы — не товар» 2) «ИИ, который тебя не продаёт» 3) «Приватный ИИ в браузере»
- Title2 (≤30): 1) «Без слежки» 2) «Без лишних логинов» 3) «Только ты и ответ»
- Text (≤81): 1) «Спрашивай ИИ по странице, не отдавая данные рекламе.» 2) «Никакого профиля и трекинга — только помощь по тексту.» 3) «ИИ работает приватно и показывает источники.»

**Угол C — прозрачность**
- Title (≤56): 1) «Видно, что ИИ делает с данными» 2) «Честный ИИ без скрытого сбора» 3) «ИИ с понятной политикой данных»
- Title2 (≤30): 1) «Ничего лишнего не собираем» 2) «Ответ со ссылками» 3) «На русском, без VPN»
- Text (≤81): 1) «Понятно, какие данные нужны, а какие — нет. Ответы со ссылками.» 2) «Прозрачно с данными и без VPN. Спроси прямо на странице.» 3) «ИИ по странице с честной политикой и источниками.»

## 3. Изображение (носитель РСЯ)

**Технические требования (для всех вариантов):**
- Файлы JPG/PNG, четыре размера РСЯ (px): **300×600**, **240×400**, **300×250**, **300×300**.
  Макет адаптируем под пропорции: 300×600 и 240×400 — вертикальные (текст сверху/снизу, телефон в центре);
  300×250 — горизонтальный прямоугольник (телефон справа, текст слева); 300×300 — квадрат (компактно, минимум текста).
- Текста на картинке **не более 20%** площади, крупно и читаемо на телефоне; высокий контраст буквы/фон.
- **Запрещено:** суммы, проценты, сроки; чужие логотипы и названия (Яндекс, Google, OpenAI и т.п.);
  выдуманные несуществующие экраны; мелкий нечитаемый текст. Шрифт и палитра — из бренд-гайда (приложить).

**Вариант 1 — «замок на диалоге» (спокойный-технологичный):**
- **Субъект:** смартфон в руке, держат вертикально, экран развёрнут к зрителю. На экране — открытая
  статья (нейтральный текст-«рыба», без узнаваемых брендов), поверх неё снизу всплывает карточка
  ответа ИИ из 2–3 строк, рядом со строкой ответа — иконка закрытого навесного замка.
- **Композиция:** телефон занимает правые 60% кадра, смещён вправо; слева — свободное поле под надпись.
  Фокус — на карточке ответа с замком (резко), фон страницы слегка размыт.
- **Сцена/фон:** однотонный спокойный фон бренд-цвета без предметов.
- **Свет:** мягкий рассеянный, источник слева сверху, без жёстких теней.
- **Стиль:** чистая коммерческая 3D/UI-визуализация, минимализм.
- **Надпись:** «Не следит» — слева по центру по вертикали, крупно, в одну строку.
- **Рука:** взрослого человека, нейтральная, без украшений/часов с логотипами; кожа естественная.

**Вариант 2 — «данные остаются у тебя» (строгая метафора, без людей):**
- **Субъект:** по центру — стилизованный силуэт диалога ИИ (облачко с 2 строками ответа); справа от
  него — закрытый сейф/щит; **перечёркнутый контур «глаза слежки»** в правом верхнем углу (тонкая линия).
- **Композиция:** симметрично, диалог в центре, щит справа, перечёркнутый глаз — маленький акцент сверху справа.
- **Сцена/фон:** глубокий однотонный бренд-цвет, лёгкий градиент к краям.
- **Свет:** ровный, без бликов; объекты с мягкой тенью-подложкой.
- **Стиль:** строгая флэт-иллюстрация, тонкие линии, без декоративного шума.
- **Надпись:** «Твои запросы остаются твоими» — нижняя треть, по центру, две строки максимум.

**Вариант 3 — «что мы не собираем» (функциональный интерфейс, без людей):**
- **Субъект:** крупный план чистого интерфейса браузера: поле вопроса вверху, ниже — ответ ИИ с
  двумя подсвеченными ссылками-источниками, сбоку — короткий список-чеклист «что не собираем»
  (3 пункта-плейсхолдера в виде иконок-галочек, без конкретного текста-обещаний).
- **Композиция:** интерфейс по центру, занимает ~80% кадра; чеклист — узкой колонкой справа.
- **Сцена/фон:** светлый нейтральный, интерфейс «парит» с мягкой тенью.
- **Свет/стиль:** ровный студийный, плоский UI-мокап, аккуратные отступы.
- **Надпись:** «Понятно, что с данными» — верх кадра, одна строка.
- **Запреты варианта:** не указывать конкретные обещания политики текстом (только иконки), чтобы не давать невыполнимых гарантий.

**Видео (опц.):** 8–12 c, вертикаль 9:16 и 1:1. Кадр 1 (0–2 c): рука открывает статью на телефоне.
Кадр 2 (2–6 c): набирает вопрос, появляется ответ ИИ со ссылками. Кадр 3 (6–9 c): иконка замка +
надпись «не следит». Финал (9–12 c): кнопка «скачать». Субтитры обязательны (звук часто выключен).

## 4. Что можно и нельзя
- Без сумм/процентов/сроков; без «лучший/№1/гарантированно»; без давления срочностью. erid — площадка.
