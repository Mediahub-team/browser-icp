# Креатив — offer-02-percent-big / ICP-02 (Директ Поиск · текст-графика)

**Источники:** [[offer-02-percent-big]] · [[icp-02-site-big-checks]] · [[market-landscape]] §2.1/§8.

## 0. Привязка
- **Оффер:** [[offer-02-percent-big]] · **ICP / аудитория:** [[icp-02-site-big-checks]]
- **Площадка:** Яндекс Директ (Поиск) + РСЯ-ретаргет
- **Формат:** текст-графика (Поиск/РСЯ)
- **Боль/триггер:** на крупном чеке вне «категории месяца» возврат мизерный · **угол:** % на крупных, без лимита категории
- **Главная метрика:** CTR Поиска, CPC (дорогой), CPS

## 1. Сообщение (ядро)
- **Главный посыл:** «Повышенный процент на дорогих покупках — без категории месяца и её лимита.»
- **RTB / доказательство:** ощутимый % у партнёров на крупном чеке через браузер; не зависит от «угаданной» категории банка; пруф крупной выплаты; «по оферте».
- **CTA:** «Записаться в лист ожидания».
- **Слова-маркеры:** «процент на крупных», «без категории месяца», «без лимита». · **Слова-табу:** «фикс», «10 рублей», «копейки»; **конкретные % до фиксации сетки**; суммы/сроки.

## 2. Заголовки для A/B
1. «Дорогая покупка? Верни процентом — без категории месяца.» — проверяет: боль «категория не та».
2. «Повышенный кешбэк на технику — без лимита банка.» — проверяет: боль лимита повышенного кешбэка.
3. «Не 1% на крупном чеке — процент у партнёров.» — проверяет: отстройку от базового банковского 1%.

## 3. Бриф по формату
**Директ Поиск (текст).** Заголовок ≤ лимит: «Кешбэк процентом на крупные покупки — через браузер». Текст ≤ лимит: «Не зависит от категории месяца. Возврат у партнёров». Быстрые ссылки: «Как работает», «Лист ожидания». Без конкретных %.
**РСЯ (текст-графика).** Изображение: чистая иллюстрация «крупная покупка → % возврата» (без числа), без стоков/мелкого текста.

## 4. Визуальный бриф
- Бренд-токены; настроение «рационально, для считающих». Акцент на «процент» (без указания величины до фиксации сетки).
- **Честно:** показываем механику %-возврата, **без конкретных %/сумм**; не рисуем партнёров, с кем нет договорённости.
- Mobile + desktop, контраст AA.

## 5. Соответствие и ограничения
- ⚠️ **Под гейтом сетки:** без конкретных % партнёров, пока не зафиксированы. Без связывающих цифр/сроков; без давления. Модерация Директ.

## 6. Гипотеза и измерение
- Проверяет: заходит ли **%-рамка** на gate-passed крупных чеках (модель×профиль). Ожидаем приличный CTR на горячем поиске, дорогую и редкую конверсию. Кросс X-percent (на ICP-03). Сверка — этап 9.
