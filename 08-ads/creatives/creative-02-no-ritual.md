# Креатив — «Кешбэк без ритуала» (под [[offer-02-no-ritual]])

- **Формат:** короткое вертикальное видео (РСЯ/VK) + статика-дубль для Поиска.
- **Площадка:** [[icp-02-cashback-disillusioned]] (Яндекс Директ РСЯ, VK).

## Тексты объявлений (A/B)
1. **Заголовок:** «Кешбэк без единой ссылки» · **Текст:** «Браузер сам ловит покупку — никаких "перейди по ссылке". Покупай как обычно, кешбэк начислится сам».
2. **Заголовок:** «Бросил Letyshops, потому что забывал ссылку?» · **Текст:** «Этот ловит покупку сам. Без расширений и ритуалов».
3. **Заголовок:** «Покупай как обычно — кешбэк сам» · **Текст:** «Без условий, без партнёрских ссылок. Возврат рублями на карту».

## Сценарий видео (15 сек)
- 0–4 с: рука тянется «перейти по ссылке» → перечёркнуто, подпись «раньше: забыл → ноль».
- 4–10 с: обычная покупка в браузере → всплывает «+кешбэк начислен» без действий.
- 10–15 с: история операций, статус «Проверяем» → подтверждено. CTA: «Поставь — и забудь про ссылки».

## Визуал-бриф
Бренд-токены из Figma (см. [landing/](../tools/landing/README.md)). Акцент на «само/без действий».
Тон — лёгкий, бытовой. Без обещаний конкретных сумм (ограничение этапа 6).
