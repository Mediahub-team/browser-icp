# Креатив — «Пруф вывода» (ICP-03, угол доверия / K3)

**Источники:** [[offer-03-payout-proof]] · [[icp-03-cashback-optimizers]] §6/§8 · [[comparison-2026-06-10]] §6 (K3 — сквозной тормоз).

> ТЗ на рекламный креатив под оффер. Один файл = один оффер × ICP. Описание **общее, без привязки к
> платформе**. Угол — **«пруф вывода»**: снимает недоверие к выплате (K3) у сегмента, видевшего невыплаты агрегаторов.
>
> ⚠️ **Честность (K3).** Без связывающих цифр (%/сумма/срок); без обещаний против инвариантов
> [[product-functionality]] §2; killed-механику не воскрешаем. Пруфы — только реальные, без фейк-скринов.
> 🔑 Лексика отзеркалена из Bukvarix ([keyword-research](../keyword-research/keyword-research-icp-03-cashback-optimizers.md)): «отмена кэшбэка», «начисление кэшбэка», «кэшбэк не пришёл». Форма — «кэшбэк». Продающие фразы написаны заново через `russian-copywriting` (обращение на «ты»).

## 0. Привязка
- **Оффер:** `07-offers/offer-03-payout-proof` · **ICP / аудитория:** `02-icp/icp-03-cashback-optimizers`
- **Боль/триггер (этап 6, тема ×6 — K3):** недоверие к выплате нового бренда; «условия выполнены — кэшбэк не пришёл». · **Ведущий рычаг/угол:** прозрачный статус начисления + публичная витрина выплат + оферта.
- **Главная метрика:** CPC + стоимость целевого действия (клик «скачать» → действие на лендинге); CTR — диагностика.

## 1. Сообщение (ядро, едино для всех углов)
- **Главный посыл (языком клиента):** «Кэшбэк видно на каждом шаге: начислили, подтвердили, вывели. С пруфами.»
- **RTB / доказательство:** двухфазный статус «Проверяем → Подтверждено → Выплачено»; публичная лента реальных выводов; выплата закреплена публичной офертой (заземление на рыночный риск, не «наш недострой»).
- **CTA:** прямое **«скачать»**. Лендинг по клику честно раскрывает пред-продукт (извинение) и фиксирует спрос — разведка спроса, не обман.
- **Слова-маркеры:** «пруф вывода», «реальные выплаты», «видно каждый статус», «по оферте». · **Слова-табу (ICP §6):** обещания мгновенного вывода, которые не подтвердить; неподтверждённые %/суммы/сроки; «гарантированно/100 %» (ФЗ-38).

## 2. Углы и формулировки (A/B/C тест)
> 3 угла — разные акценты одного оффера. Внутри угла — по 3 заголовка и 3 подписи (заготовки для
> дизайнера: выбрать по одной на угол). Заголовок ≤56, подпись ≤81. Фактическая длина в скобках.

**Угол A — «статус на каждом шаге»** — проверяет: снимает ли прозрачность пути кэшбэка страх «зажмут».
- Заголовки (≤56): 1) «Каждый рубль кэшбэка видно: от начисления до вывода» (51) 2) «Кэшбэк со статусом: начислили, подтвердили, вывели» (50) 3) «Видно, где твой кэшбэк на каждом шаге» (37)
- Подписи (≤81): 1) «Статус каждого начисления открыт: проверяем, подтвердили, выплатили. Скачай.» (76) 2) «Не гадаешь, дойдёт ли кэшбэк. Видишь его путь до вывода. Скачай браузер.» (72) 3) «Каждое начисление со статусом, без чёрного ящика агрегаторов. Скачай и проверь.» (79)

**Угол B — «лента реальных выплат»** — проверяет: работает ли социальное доказательство (чужие выводы) до установки.
- Заголовки (≤56): 1) «Лента реальных выплат — смотри до установки» (43) 2) «Сначала посмотри выплаты, потом ставь браузер» (45) 3) «Кэшбэк не пришёл? Тут видно каждый статус» (41)
- Подписи (≤81): 1) «Открытая лента выводов — посмотри реальные выплаты, потом скачивай браузер.» (75) 2) «Решай по фактам, не по обещаниям: смотри ленту выплат. Потом скачай.» (68) 3) «У агрегаторов кэшбэк терялся. Тут каждый статус виден. Скачай и сравни.» (71)

**Угол C — «по оферте, не на словах»** — проверяет: усиливает ли юридическое закрепление (оферта) доверие у скептика.
- Заголовки (≤56): 1) «Кэшбэк по оферте, а не на словах» (32) 2) «Выплаты по оферте — кэшбэк, который приходит» (44) 3) «Не обещаем на словах — выплата по оферте» (40)
- Подписи (≤81): 1) «Выплата закреплена офертой, а не обещанием в рекламе. Скачай и прочти.» (70) 2) «Не «доверьтесь нам»: условия выплаты в публичной оферте. Скачай браузер.» (72) 3) «Кэшбэк выводится по оферте, статус открыт на каждом шаге. Скачай браузер.» (73)

## 3. Визуал (главный носитель — изображение)
> Подробное описание изображения, 3 вариации с разным характером (дизайнер выбирает). Видео и карусель — опции под угол-победитель.

**Изображение — 3 вариации (разный характер):**
- **Вариация 1 — строго-доказательная:** крупный план карточки кэшбэка со статусом «Проверяем → Подтверждено → Выплачено», галочки, без конкретных сумм (или с затёртыми/демонстрационными, помеченными как пример). Фокус на прозрачности пути. Палитра — бренд-токены, тон спокойно-надёжный. Честно: реальный прототип интерфейса, не AI-картинка.
- **Вариация 2 — человеческая «облегчение»:** человек проверяет ленту выплат и спокойно выдыхает — контраст с прошлым опытом «кэшбэк не пришёл». Тёплый тон, акцент на снятии тревоги. Текст ≤20%, контраст AA.
- **Вариация 3 — документально-юридическая:** фрагмент публичной оферты + бейдж «выплата закреплена офертой», сухо и по делу. Для скептика, который верит бумаге, а не картинке. Без громких слов, без процентов.
- **Общие требования:** реальный продукт/прототип, не AI-интерфейс; без мелкого нечитаемого текста; контраст AA; текст ≤20% площади; пруфы и суммы — только реальные либо явно помеченные как пример, без выдуманных балансов.

**Видео (опция).** 6–15 с, хук «кэшбэк снова не пришёл?»; биты: боль невыплаты → лента выводов → статус «Выплачено» → CTA-кадр «скачать». Субтитры (звук выключен).
**Карусель (опция).** Слайды: 1) «Проверяем» → 2) «Подтверждено» → 3) «Выплачено» → 4) лента реальных выводов → CTA «скачать» на последнем.

## 4. Соответствие и ограничения (гейт)
- Честность-констрейнты (см. шапку); без давления/таймеров; без «гарантированно/100 %/всегда выплатим» (ФЗ-38) — обещаем прозрачность статуса и оферту, не безусловную доходность.
- Любая лента выплат/отзывы с суммами — только реальные данные; на этапе пред-продукта в креативе использовать как концепт-макет с явной пометкой, не выдавать за фактические выплаты.
- **CTA «скачать» честен через лендинг:** объявление зовёт скачать, лендинг сразу раскрывает пред-продукт (извинение) и фиксирует спрос.
- Маркировка (erid/ОРД) — на уровне размещения.

## 5. Гипотеза и измерение
- **A** — снимает ли прозрачность статуса страх «зажмут». **B** — работает ли соц-доказательство (чужие выводы) сильнее обещаний. **C** — добавляет ли оферта доверия у самых требовательных. Гипотеза: payout-proof — снижатель трения поверх [offer-03-no-ritual](../../07-offers/offer-03-no-ritual.md); сам ценность не продаёт, но без него скептик не дойдёт до установки. Сигнал — стоимость действия по углу и доля доходящих до лендинга для сверки на этапе 9.
