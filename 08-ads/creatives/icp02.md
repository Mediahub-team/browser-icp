# Креативы — ICP-02 Контент-читатели (мотив A, O4–O6)

> Под офферы [[offer-icp02-summary]]. Контр-нарратив к ChatGPT: не «умный ИИ»,
> а **«работает прямо на открытой странице — без копипаста»**. Язык клиента:
> «сто непрочитанных лонгридов», «сохранил — будто прочитал», «дай суть»,
> «избранное как кладбище». Пред-продукт: CTA = лист ожидания, ведём на лендинги
> из [[recheck-preproduct-landing-2026-06-04]] (см. landings/icp02.md).
> Правило отстройки: ни одного «нейросеть/LLM/промпт» — давим на механику, не интеллект.

## O4 — «Суть из ленты» (Telegram Ads, РСЯ) → ведёт на L-O4

### Креатив O4-A (видео-демо, основной)
- **Текст (caption):** «Десять каналов за пять минут. Открыл пост → тап → суть.
  Без скролла и без копипаста — ИИ читает прямо то, что у тебя на экране.»
- **Визуал-бриф:** вертикаль 9:16, реальный экран Telegram, палец делает один тап,
  поверх поста всплывают 3 коротких буллета. Без стоков, без «робота» — только экран
  телефона. Акцент-цвет на кнопке/тапе, фон — обычная лента.
- **Сценарий видео (10–15 сек):**
  1. (0–3с) скролл длинной ленты канала, подпись «снова полчаса скролла?»;
  2. (3–6с) палец тапает по посту — кадр «тап»;
  3. (6–11с) поверх ТОЙ ЖЕ страницы выезжают 3 буллета сути, подпись «суть — прямо здесь»;
  4. (11–15с) плашка «без копипаста, без переключения вкладок» → CTA «Записаться в лист ожидания».

### Креатив O4-B (статика/карусель)
- **Текст:** «Лента канала разрослась — что важного за день? Тап по посту — и 3 буллета сути.
  Ничего никуда не копируешь.»
- **Визуал-бриф:** 2 кадра «было/стало»: слева простыня постов («тону в ленте»),
  справа тот же экран с 3 буллетами поверх. Контраст объёма. Узнаваемый интерфейс TG.

### A/B-заголовки O4
1. «Десять каналов за пять минут. Тап — и суть, без копипаста.»
2. «Лента разрослась? Тап по посту — 3 буллета сути прямо на экране.»
3. «ИИ видит то, что у тебя в ленте. Суть поста за секунды — без пересылки боту.»

## O5 — «Суть из простыни / до созвона» (VK профсообщества, РСЯ) → ведёт на L-O5

### Креатив O5-A (видео-демо, основной)
- **Текст (caption):** «Суть из простыни — до созвона. ИИ читает документ прямо на странице,
  ничего не копируя наружу. Не опозоришься, что не успел прочитать.»
- **Визуал-бриф:** вертикаль 9:16, длинный рабочий документ/лонгрид на телефоне, тап,
  поверх — суть + 2–3 ключевые цифры; у одного буллета подсветка «→ к абзацу-источнику».
  Деловой, спокойный тон, без эмодзи-кричалок. Плашка «текст не уходит во внешний чат».
- **Сценарий видео (10–15 сек):**
  1. (0–3с) скролл длинного отчёта, подпись «созвон через 10 минут, не прочитал»;
  2. (3–6с) тап по документу;
  3. (6–11с) поверх той же страницы — суть + цифры, один буллет кликается к абзацу-источнику;
  4. (11–15с) плашка «ничего не копируешь наружу» → CTA «Записаться в лист ожидания».

### Креатив O5-B (статика/карусель «было/стало»)
- **Текст:** «Было: 40 минут на простыню перед встречей. Стало: один тап — суть и цифры.
  Источник под рукой — сошлёшься на абзац, а не на пересказ.»
- **Визуал-бриф:** карусель из 2–3 кадров: «40 мин» → «1 тап» → кадр с привязкой буллета
  к месту в тексте (стрелка к абзацу). Корп-аккуратный визуал.

### A/B-заголовки O5
1. «Суть из простыни — до созвона. Без копипаста наружу.»
2. «Дай суть из этого документа. ИИ читает прямо страницу — текст не уходит во внешний чат.»
3. «Не успел прочитать к созвону? Тап — суть и цифры, со ссылкой на абзац.»

## O6 — «Разгрести сохранёнки» (Telegram Ads, VK Ads) → ведёт на L-O6

### Креатив O6-A (видео-демо, основной)
- **Текст (caption):** «Сто непрочитанных лонгридов в избранном? Открыл из сохранёнок →
  тап → суть. Разгреби кладбище — без копипаста и без чувства вины.»
- **Визуал-бриф:** вертикаль 9:16, экран «избранное/сохранённое» с длинным списком,
  счётчик «разобрано 20 из 100» растёт по мере прогона. Палец тапает по сохранёнке —
  поверх выезжает суть. Эмоция узнавания, но без давления-кричалок.
- **Сценарий видео (10–15 сек):**
  1. (0–3с) длинный список сохранёнок, подпись «сохранил — будто прочитал?»;
  2. (3–6с) открыл сохранёнку, тап;
  3. (6–11с) суть поверх страницы, счётчик «разобрано 5 из 100» тикает;
  4. (11–15с) «избранное больше не кладбище» → CTA «Записаться в лист ожидания».

### Креатив O6-B (статика/карусель)
- **Текст:** «Избранное как кладбище? Сто сохранёнок → суть каждой в один тап.
  Без копипаста — ИИ читает прямо открытую страницу.»
- **Визуал-бриф:** кадр «кладбище сохранёнок» (длинный серый список) → кадр «прочитано»
  (галочки/счётчик). Эмоциональный контраст вины и облегчения.

### A/B-заголовки O6
1. «Сто непрочитанных лонгридов? Суть каждой — в один тап. Без копипаста.»
2. «Сохранил — будто прочитал? Открой из избранного: тап — и суть.»
3. «Избранное как кладбище? Разгреби — ИИ даёт суть прямо на странице.»
