# Креатив — «Кешбэк с каждой покупки» (под [[offer-01-every-purchase]])

- **Формат:** видео-сравнение (РСЯ/VK) + статика для Поиска.
- **Площадка:** [[icp-01-deal-hunters]].

## Тексты объявлений (A/B)
1. **Заголовок:** «Кешбэк с любой покупки» · **Текст:** «Не только в избранных магазинах — со всего, что покупаешь через браузер».
2. **Заголовок:** «Letyshops возвращает с части. Этот — со всего» · **Текст:** «Гарантированный фикс за любую покупку, где угодно».
3. **Заголовок:** «Половина покупок мимо кешбэка?» · **Текст:** «Больше нет. Возврат там, где его раньше не было».

## Сценарий видео (15 сек)
- 0–5 с: карта трат, горят 3 магазина, остальное серое — «у обычного сервиса».
- 5–11 с: вся карта загорается — «у нас кешбэк со всего».
- 11–15 с: CTA «Получай кешбэк со всего, а не выборочно».

## Визуал-бриф
Метафора «вся карта трат горит». Тон — выгода/охват, для тех, кто уже считает кешбэк.
Бренд-токены из Figma. Без конкретных процентов (партнёрская сетка не зафиксирована).
