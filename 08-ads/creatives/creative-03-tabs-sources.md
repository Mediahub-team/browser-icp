# Креатив — offer-03-tabs-sources (ICP-03 знаниевые работники)

> ТЗ на креатив РСЯ. Обращение — **«вы»** (профессионалы). Multi-tab — фича сверх сборки, проверяем спрос.

## 0. Привязка
- **Оффер:** свести вкладки в ответ со ссылками · **Кому:** аналитики/консультанты, ресёрч с телефона.
- **Главная мысль:** несколько открытых страниц — один ответ со ссылками, не выходя из браузера.
- **Что измеряем:** клики «скачать» + заявки.

## 1. Сообщение
- **Главная мысль:** «Свести несколько вкладок в один ответ — со ссылками».
- **Почему верить:** ответ ссылается на каждую вкладку-источник; работает с телефона.
- **Призыв:** «скачать».
- **Должны звучать:** «вкладки», «со ссылками», «с телефона», «свести».
- **Не должно быть:** суммы, кешбэк, «лучший/№1».

## 2. Тексты объявлений (A/B/C)

**Угол A — свести вкладки**
- Title (≤56): 1) «Свести вкладки в один ответ» 2) «Несколько вкладок — один ответ» 3) «ИИ читает ваши вкладки сразу»
- Title2 (≤30): 1) «Со ссылками на источники» 2) «Прямо с телефона» 3) «Без копирования»
- Text (≤81): 1) «Открыто пять вкладок? Получите общий ответ со ссылками на каждую.» 2) «ИИ соберёт суть из всех открытых вкладок и покажет источники.» 3) «Свести источники в вывод — не выходя из браузера.»

**Угол B — ответ со ссылками**
- Title (≤56): 1) «Ответ ИИ — со ссылками» 2) «ИИ, который даёт источники» 3) «Факты со ссылками, не выдумки»
- Title2 (≤30): 1) «Можно проверить» 2) «Из ваших вкладок» 3) «По делу, без воды»
- Text (≤81): 1) «Каждый ответ — со ссылкой на источник. Удобно проверить перед встречей.» 2) «ИИ отвечает по вашим вкладкам и показывает, откуда взял.» 3) «Нужны не общие слова, а факты со ссылками — он их даёт.»

**Угол C — ресёрч с телефона**
- Title (≤56): 1) «Ресёрч с телефона без мучений» 2) «Разобраться в теме на ходу» 3) «ИИ для ресёрча в дороге»
- Title2 (≤30): 1) «Свести вкладки в вывод» 2) «Со ссылками» 3) «Между встречами»
- Text (≤81): 1) «Соберите суть из открытых вкладок прямо с телефона, со ссылками.» 2) «Подготовиться к встрече по дороге — ИИ сведёт источники.» 3) «Не переключаясь, получите вывод со ссылками.»

## 3. Изображение (носитель РСЯ)

**Технические требования (для всех вариантов):**
- JPG/PNG, четыре размера РСЯ (px): **300×600**, **240×400**, **300×250**, **300×300**.
  Макет адаптируем под пропорции: 300×600 и 240×400 — вертикальные; 300×250 — горизонтальный прямоугольник; 300×300 — квадрат (минимум текста).
- Текста ≤20% площади, крупно и читаемо; высокий контраст. Шрифт/палитра — бренд-гайд (приложить).
- **Запрещено:** суммы/проценты/сроки; чужие логотипы и названия; выдуманные экраны; мелкий текст.

**Вариант 1 — «вкладки → один свод» (деловой):**
- **Субъект:** смартфон в руке делового человека (на вид 30–45 лет, нейтральная одежда, без лиц
  крупным планом — рука и часть плеча). На экране — ряд из 4–5 миниатюр вкладок сверху, под ними —
  карточка ответа ИИ из 3 строк, в конце ответа — 3 маленькие иконки-ссылки (источники).
- **Композиция:** телефон в центре-справа (60% кадра), вкладки вверху экрана выстроены в ряд,
  свод-ответ — крупно по центру экрана (в фокусе); слева — поле под надпись.
- **Сцена/фон:** размытый деловой интерьер (офис/кафе) в холодных бренд-тонах, без узнаваемых деталей.
- **Свет:** дневной мягкий, слева; лёгкая глубина резкости (фон размыт).
- **Стиль:** чистая коммерческая UI-визуализация.
- **Надпись:** «5 вкладок → один ответ» — слева по центру, крупно, одна строка.

**Вариант 2 — «было/стало» (сравнение, без людей):**
- **Субъект:** разделённый кадр вертикальной линией. **Слева** — хаос: десяток наложенных друг на
  друга миниатюр вкладок, стрелки в разные стороны, тусклый сероватый тон. **Справа** — порядок: один
  аккуратный экран с ответом ИИ и тремя подсвеченными ссылками, яркий бренд-цвет.
- **Композиция:** ровно 50/50, граница по центру; левая половина визуально «тяжёлая», правая «лёгкая».
- **Свет/стиль:** флэт-иллюстрация; слева пониженная насыщенность, справа полная.
- **Надпись:** слева мелко «было», справа «стало» — у нижнего края каждой половины.

**Вариант 3 — «5 вкладок → 1 ответ» (функциональный, без людей):**
- **Субъект:** крупный UI-мокап: сверху — ряд из 5 подписанных вкладок-плейсхолдеров (без реального
  контента), посередине — стрелка слияния вниз, снизу — единая карточка ответа ИИ с тремя ссылками-источниками.
- **Композиция:** строго по центру, вертикальный поток сверху вниз, симметрия; ~80% кадра.
- **Сцена/фон:** светлый нейтральный, мокап с мягкой тенью.
- **Свет/стиль:** ровный студийный, плоский интерфейс, аккуратные отступы.
- **Надпись:** «Со ссылками на источники» — нижняя треть, одна строка.

**Видео (опц.):** 8–12 c, 1:1 и 16:9. Кадр 1 (0–2 c): на телефоне открыто много вкладок. Кадр 2
(2–6 c): запрос «свести» → миниатюры «стягиваются» в один ответ. Кадр 3 (6–9 c): ответ со ссылками
крупно. Финал (9–12 c): кнопка «скачать». Субтитры обязательны.

## 4. Что можно и нельзя
- Без сумм/процентов/сроков; без «лучший/№1/гарантированно»; без таймеров. erid — площадка.
