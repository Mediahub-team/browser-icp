# Креатив — offer-01-study (ICP-01 студенты)

> ТЗ на креатив РСЯ. Обращение — **«ты»** (молодёжь, соцсети). Резерв/замер охвата (T4).

## 0. Привязка
- **Оффер:** пересказ учёбы прямо в браузере · **Кому:** студенты, много читают с телефона, бесплатность критична.
- **Главная мысль:** быстро понять статью/лекцию, не копируя, бесплатно.
- **Что измеряем:** клики «скачать» + заявки.

## 1. Сообщение
- **Главная мысль:** «Перескажет статью или лекцию прямо в браузере».
- **Почему верить:** спрашиваешь по открытой странице; бесплатно, на русском, без VPN; ответ со ссылками.
- **Призыв:** «скачать».
- **Должны звучать:** «перескажет», «бесплатно», «без VPN», «по учёбе».
- **Не должно быть:** суммы, кешбэк, «лучший/№1», «гдз/решебник».

## 2. Тексты объявлений (A/B/C)

**Угол A — пересказ учёбы**
- Title (≤56): 1) «Перескажет лекцию за минуту» 2) «Пойми статью быстро» 3) «ИИ-помощник по учёбе»
- Title2 (≤30): 1) «Прямо в браузере» 2) «Бесплатно» 3) «Без копирования»
- Text (≤81): 1) «Открой статью или методичку и спроси — ИИ объяснит и перескажет.» 2) «Не успеваешь прочитать? ИИ вытащит главное по странице.» 3) «Спроси по лекции прямо в браузере — ответит со ссылками.»

**Угол B — бесплатно, без VPN**
- Title (≤56): 1) «ИИ для учёбы — бесплатно» 2) «Нейросеть для учёбы без VPN» 3) «Бесплатный ИИ по учёбе»
- Title2 (≤30): 1) «На русском» 2) «Без подписки» 3) «Сразу в браузере»
- Text (≤81): 1) «ИИ-помощник по учёбе. Бесплатно, на русском, без VPN.» 2) «Не нужен VPN и подписка — спроси по странице и учись быстрее.» 3) «Бесплатный ИИ прямо в браузере для статей и лекций.»

**Угол C — не копировать**
- Title (≤56): 1) «Не копируй в чат — спроси тут» 2) «ИИ видит твою страницу» 3) «Спроси прямо по тексту»
- Title2 (≤30): 1) «Без копипаста» 2) «Ответ со ссылками» 3) «Быстрее к сути»
- Text (≤81): 1) «Не носи текст в чат — спроси ИИ прямо на странице с лекцией.» 2) «ИИ видит, что ты читаешь. Перескажет и ответит.» 3) «Открыл — спросил — понял. Без копирования.»

## 3. Изображение (носитель РСЯ)

**Технические требования (для всех вариантов):**
- JPG/PNG, три кадрирования: **1:1 (1080×1080)**, **16:9 (1280×720)**, **3:4 (1080×1440)** + вертикаль **9:16** для Reels.
- Текста ≤20% площади, крупно и читаемо; высокий контраст. Шрифт/палитра — бренд-гайд (приложить).
- **Запрещено:** суммы/проценты/сроки; чужие логотипы и названия; выдуманные экраны; «гдз/решебник» в кадре.

**Вариант 1 — «понял лекцию» (студенческий):**
- **Субъект:** студент (на вид 18–22 лет, в кадре рука и плечо, лицо не крупно) держит смартфон. На
  экране — открытая лекция/методичка (нейтральный учебный текст), снизу всплывает короткий пересказ ИИ из 3 строк.
- **Композиция:** телефон по центру-справа (60%), пересказ — в фокусе; слева поле под надпись.
- **Сцена/фон:** учебная обстановка (стол, тетрадь не в фокусе) в светлых бренд-тонах, размыто.
- **Свет:** дневной мягкий; лёгкая глубина резкости.
- **Стиль:** живая, лёгкая коммерческая визуализация (молодёжный тон, но без китча).
- **Надпись:** «Понял за минуту» — слева по центру, крупно.

**Вариант 2 — «было/стало» (сравнение, без людей):**
- **Субъект:** кадр поделён вертикально. **Слева** — длинная «простыня» текста, ощущение «много и
  скучно», тусклый тон. **Справа** — короткая суть из 3 пунктов с двумя ссылками, яркий бренд-цвет.
- **Композиция:** 50/50, граница по центру; слева плотный текст, справа воздух и структура.
- **Свет/стиль:** флэт-иллюстрация; слева пониженная насыщенность, справа полная.
- **Надпись:** слева «вся статья», справа «суть» — у нижнего края.

**Вариант 3 — «вопрос по статье → ответ» (функциональный, без людей):**
- **Субъект:** UI-мокап: вверху статья с текстом-плейсхолдером, ниже — поле вопроса, ещё ниже —
  ответ ИИ с двумя подсвеченными ссылками.
- **Композиция:** вертикальный поток по центру, ~80% кадра.
- **Сцена/фон:** светлый нейтральный, мокап с мягкой тенью.
- **Свет/стиль:** ровный студийный, плоский интерфейс.
- **Надпись:** «Бесплатно, без VPN» — нижняя треть, одна строка.

**Видео (опц.):** 8–12 c, **вертикаль 9:16** (Reels) + 1:1. Кадр 1 (0–2 c): студент листает длинную
лекцию, вздыхает. Кадр 2 (2–6 c): спрашивает прямо на странице → короткий пересказ. Кадр 3 (6–9 c):
суть со ссылками крупно. Финал (9–12 c): кнопка «скачать». Субтитры обязательны.

## 4. Что можно и нельзя
- Без сумм/процентов/сроков; без «лучший/№1/гарантированно»; без «гдз/решебник». erid — площадка.
