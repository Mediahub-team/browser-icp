# Креатив — offer-01-study (ICP-01 студенты)

> ТЗ на креатив РСЯ. Обращение — **«ты»** (молодёжь, соцсети). Резерв/замер охвата (T5).

## 0. Привязка
- **Оффер:** пересказ учёбы прямо в браузере · **Кому:** студенты, много читают с телефона, бесплатность критична.
- **Главная мысль:** быстро понять статью/лекцию, не копируя, бесплатно.
- **Что измеряем:** клики «скачать» + заявки.

## 1. Сообщение
- **Главная мысль:** «Перескажет статью или лекцию прямо в браузере».
- **Почему верить:** спрашиваешь по открытой странице; бесплатно, на русском, без VPN; ответ со ссылками.
- **Призыв:** «скачать».
- **Должны звучать:** «перескажет», «бесплатно», «без VPN», «по учёбе».
- **Не должно быть:** суммы, кешбэк, «лучший/№1», «гдз/решебник».

## 2. Тексты объявлений (A/B/C)

**Угол A — пересказ учёбы**
- Title (≤56): 1) «Перескажет лекцию за минуту» 2) «Пойми статью быстро» 3) «ИИ-помощник по учёбе»
- Title2 (≤30): 1) «Прямо в браузере» 2) «Бесплатно» 3) «Без копирования»
- Text (≤81): 1) «Открой статью или методичку и спроси — ИИ объяснит и перескажет.» 2) «Не успеваешь прочитать? ИИ вытащит главное по странице.» 3) «Спроси по лекции прямо в браузере — ответит со ссылками.»

**Угол B — бесплатно, без VPN**
- Title (≤56): 1) «ИИ для учёбы — бесплатно» 2) «Нейросеть для учёбы без VPN» 3) «Бесплатный ИИ по учёбе»
- Title2 (≤30): 1) «На русском» 2) «Без подписки» 3) «Сразу в браузере»
- Text (≤81): 1) «ИИ-помощник по учёбе. Бесплатно, на русском, без VPN.» 2) «Не нужен VPN и подписка — спроси по странице и учись быстрее.» 3) «Бесплатный ИИ прямо в браузере для статей и лекций.»

**Угол C — не копировать**
- Title (≤56): 1) «Не копируй в чат — спроси тут» 2) «ИИ видит твою страницу» 3) «Спроси прямо по тексту»
- Title2 (≤30): 1) «Без копипаста» 2) «Ответ со ссылками» 3) «Быстрее к сути»
- Text (≤81): 1) «Не носи текст в чат — спроси ИИ прямо на странице с лекцией.» 2) «ИИ видит, что ты читаешь. Перескажет и ответит.» 3) «Открыл — спросил — понял. Без копирования.»

## 3. Изображение (носитель РСЯ)
- Форматы: 1:1 / 16:9 / 3:4; текст ≤20%; бренд-цвета; без сумм/логотипов/выдуманных экранов.
- **Вариант 1 — студенческий:** телефон с методичкой/лекцией, поверх — короткий пересказ; человек 18–22 лет.
- **Вариант 2 — «было/стало»:** слева длинный текст, справа — короткая суть со ссылками.
- **Вариант 3 — функциональный:** интерфейс «вопрос по статье → ответ»; надпись «бесплатно»; без людей.
- **Видео (опц.):** 8–12 c (вертикаль под Reels) — открыл лекцию → спросил → суть → «скачать».

## 4. Что можно и нельзя
- Без сумм/процентов/сроков; без «лучший/№1/гарантированно»; без «гдз/решебник». erid — площадка.
