# Креатив — «Видишь каждое начисление» (под [[offer-02-payout-proof]])

- **Формат:** статика/карусель со скриншотом истории начислений (Поиск high-intent + РСЯ).
- **Площадка:** [[icp-02-cashback-disillusioned]] (Яндекс Директ Поиск по «не пришёл кешбэк»).

## Тексты объявлений (A/B)
1. **Заголовок:** «Кешбэк, который видно» · **Текст:** «Каждое начисление — в истории операций. Статус каждой покупки, вывод на карту».
2. **Заголовок:** «Уже обещали кешбэк и не выплатили?» · **Текст:** «Здесь виден каждый рубль: что начислено, за что, когда».
3. **Заголовок:** «Прозрачный кешбэк без чёрного ящика» · **Текст:** «Видишь статус каждой покупки — никаких "потерялось"».

## Сценарий (карусель, 3 слайда)
- Слайд 1: запрос «кешбэк не пришёл» → «Знакомо?».
- Слайд 2: скриншот истории начислений со статусами «Проверяем»/подтверждено.
- Слайд 3: вывод на карту. CTA: «Посмотри, как считается каждый кешбэк».

## Визуал-бриф
Доверие через прозрачность: реальный экран истории, без глянца. Бренд-токены из Figma.
⚠️ Не указывать конкретные суммы/сроки выплаты (бэкенд выплат достраивается).
