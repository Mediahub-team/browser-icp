# Креатив — offer-05-no-scan / ICP-05 (VK/TG/инфлюенсер · видео + пост-бриф)

**Источники:** [[offer-05-no-scan]] · [[icp-05-family-shoppers]] · [[market-landscape]] §3.

## 0. Привязка
- **Оффер:** [[offer-05-no-scan]] · **ICP / аудитория:** [[icp-05-family-shoppers]]
- **Площадка:** VK Ads (родители) + Telegram (мам-каналы) + инфлюенсер (мам-блогеры)
- **Формат:** видео 9:16 + инфлюенсер пост-бриф
- **Боль/триггер:** мелочь мимо кешбэка + скан чеков надоел · **угол:** копится без сканов (vs Едадил)
- **Главная метрика:** CTR в родительских сообществах → CPS

## 1. Сообщение (ядро)
- **Главный посыл:** «Копится со всех мелких трат само — без сканов чеков и ссылок.»
- **RTB / доказательство:** кешбэк со всех покупок через браузер автоматически; не нужно сканировать чеки и помнить про позиции; баланс «накопила за месяц»; вывод на карту.
- **CTA:** «Записаться в лист ожидания».
- **Слова-маркеры:** «копится само», «без сканов», «со всего», «на семью». · **Слова-табу:** «партнёрские ставки», жаргон, «ещё одна задача»; точные суммы.

## 2. Заголовки для A/B
1. «Сто заказов на семью в месяц — и всё мимо кешбэка?» — проверяет: объём мелочи как боль.
2. «Едадил надоел? Кешбэк копится без сканов чеков.» — проверяет: прямую отстройку от субститута.
3. «Покупай для семьи через браузер — копится само.» — проверяет: convenience-формулировку.

## 3. Бриф по формату
**Видео (9:16, 8–12 с).** Хук 0–2 с: гора чеков / усталое сканирование в приложении чеков. 3–7 с: «А можно без сканов — копится со всех покупок само» → растущий баланс. 8–12 с: CTA waitlist. Субтитры; тёплый «семейный» тон.
**Инфлюенсер пост-бриф (мам-блогер).** Своими словами: «закупаюсь на семью онлайн, кешбэка с мелочи не было; нашла браузер — копится само, без сканов». Обязательно: честно «продукт на старте, это лист ожидания»; НЕ обещать суммы. Метка/UTM.

## 4. Визуальный бриф
- Бренд-токены; настроение тёплое, «для своих», без глянца-стока.
- **Честно:** показываем авто-накопление баланса как механику; без конкретных сумм; реальные мам-отзывы (плейсхолдеры до сбора).
- Mobile-first, контраст AA.

## 5. Соответствие и ограничения
- Инфлюенсер обязан раскрыть рекламу (метка), не обещать выплат/сумм. Без давления. Без связывающих цифр. Модерация VK/TG.

## 6. Гипотеза и измерение
- Проверяет: бьёт ли «без сканов» по субституту Едадил → CTR/заявки в мам-сообществах. Риск — gate (часть закупок в приложении/офлайн). Кросс X3 (passive-stack на ICP-05). Сверка — этап 9.
