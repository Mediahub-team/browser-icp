# Таргетинг — ICP-05 «Охотники за выгодой» + ICP-06 «Heavy-buyers» (мотив C, доверие к выплате)

> Пред-продуктовый **лендинг-тест**: продукт НЕ запущен, никому не платим. CTA = запись в
> **лист ожидания**, меряем спрос. Оффер: [[offer-c-trust-gated]] (O11 для 05, O12 для 06).
> Угол — НЕ «кешбэк = выгода», а **доверие к выплате**: «Кешбэк, который реально выводится —
> честно, без холда». На креативах/лендинге — эмоциональный угол, **БЕЗ связывающих цифр**
> (конкретный %/порог/срок) — продукт может не вытянуть (honor-at-launch).
>
> 🎓 **ОБУЧАЮЩАЯ ЯЧЕЙКА. Заявки ДИСКОНТИРУЕМ.** По калибровке кешбэк — НЕ боль, аудитория
> лояльна Letyshops → ждём **МНОГО заявок при НИЗКОМ качестве интента**. Цель ячейки —
> измерить **разрыв «заявки ↔ интент»**, а НЕ выиграть тест по числу signup.

## Параметры по площадкам

### Telegram Ads (приоритет — оба сегмента)
- **Формат:** реклама в каналах + посевы в кешбэк/купонных/промо-каналах.
- **Каналы (O11, ICP-05):** кешбэк-агрегаторы, купонные, «скидки/халява», промокоды, «находки».
- **Каналы (O12, ICP-06):** каналы про покупки/находки с МП, быт, родительство/детское (под S-угол).
- **Гео:** РФ. **Возраст:** 25–45.
- ⚠️ Посев в скидочных пабликах = там же сидит наша будущая аудитория → негатив виден сразу.

### VK Ads
- **Формат:** таргет по сообществам/интересам.
- **O11 (ICP-05):** сообщества скидок/выгоды, кешбэк, купоны, «экономия», конкуренты (Letyshops/Backit/Megabonus).
- **O12 (ICP-06):** интересы шопинга/быта, «находки с МП», родительство; для S-угла — детские/бытовые сообщества + калькулятор упущенного на типовом объёме Heavy.
- **Гео:** РФ. **Возраст:** 28–45, без жёсткого гендер-сплита (для O12 допустим уклон в женскую аудиторию бытовых закупок).
- **Look-alike:** от вторичного сигнала интента (чекбокс «готов попробовать первым»), а НЕ от голых signup.

## Бюджет (обучающий, ограниченный)
- **Малый суммарный бюджет** — ячейка обучающая, не выигрышная. Делим примерно поровну O11/O12,
  с резервом на VK под S-угол O12 (калькулятор/«детское») как самый валидный крючок.
- **Ранний kill:** при выгорании раннего качества интента (см. пороги) — не доливаем, фиксируем разрыв.

## Метрики и пороги
- **CTR** — притяжение угла «доверие к выплате» vs привычный «кешбэк = выгода».
- **signup-rate** (CTR лендинга → заявка), **cost-per-signup**.
- **🔑 Качество интента / дисконт заявок (ОБЯЗАТЕЛЬНО):**
  - доля микро-коммитмента (чекбокс «готов попробовать первым») / все заявки;
  - распределение ответов микро-вопроса «что для вас главное?» (кешбэк vs проверка vs суть);
  - **дисконтированный signup** = заявки × доля интента → честная метрика ячейки;
  - **разрыв signup↔интент** = (raw signup) − (дисконтированный) — главный результат.
- **Стоп-метрика:** негатив «развод / не выплатили» в комментах посевов.
- **Kill-критерий:** cost-per-signup выше X **или** доля микро-коммитмента ниже Y → выключаем.

## Дизайн сплит-теста
- **Изоляция «угол»:** O11 (доверие) и O12 (калькулятор+S) — на своих сегментах; плюс **кросс**:
  - O11 (доверие к выплате) → прокинуть на ICP-06 **без** S-бонуса (решает ли доверие само по себе против привычки к приложению МП);
  - O12 (калькулятор упущенного) → на ICP-05 **без** блока «детское» (заходит ли персонализация объёма дешёвым охотникам).
- **Изоляция «площадка»:** один оффер × Telegram vs VK.
- Переменные не смешиваем: один оффер на несколько аудиторий и несколько углов на одну аудиторию.

## Гипотезы перед запуском (сверить на этапе 9)
1. **Ждём ВЫСОКИЙ raw-signup** (кешбэк любят все, оба сегмента лояльны Letyshops) — выше «честных» ячеек S/A.
2. **Ждём НИЗКОЕ качество интента:** низкая доля микро-коммитмента, ответы микро-вопроса размазаны/«из любопытства» → **большой разрыв signup↔интент**.
3. Угол «доверие к выплате» даёт CTR не ниже привычного «выгода/процент» — крючок не в проценте, а в «в этот раз точно выведешь».
4. **O12 S-угол** («проверь детское» + калькулятор) даёт более качественный интент, чем чистый C — частичная валидация S на Heavy.
5. **Результат ячейки — не победа, а число:** насколько signup переоценивает реальный интент по C-офферу (калибровочный дисконт-коэффициент для этапа 9).
