# План пред-продуктового лендинг-теста — 2026-06-04

**Источники:** [[offers-matrix]] (офферы O1–O12), [[recheck-preproduct-landing-2026-06-04]] (рамка теста).

> **Тип теста.** Продукт ещё не запущен. Тестируем **спрос на обещание**: объявление →
> лендинг → **CTA «Записаться в лист ожидания»**. Метрика — НЕ установка/активация, а
> **CTR → signup, cost-per-signup (CPS) + качество интента**. Решение — по
> **`заявки × качество интента`**, не по голым заявкам.

## Метрики
- **Воронка:** показы → CTR → клик (CPC) → **signup-rate (лендинг→заявка)** → **CPS**.
- **Качество интента (ключ теста):** после заявки — микро-вопрос «что для вас главное?»
  (проверить товар / суть страницы / источники / кешбэк) + чекбокс **«готов попробовать первым»**.
  - **intent-score** = доля «готов попробовать первым» × доля «целевого» ответа в микро-вопросе.
- **Решающая метрика:** **quality-adjusted CPS** = CPS / intent-score (чем ниже — тем лучше).
- Вторично: scroll-depth лендинга, клик по вторичному CTA.

## Kill-критерии (зафиксированы до запуска)
Ячейку выключаем при любом из:
- CPS > 2× медианы фокус-ячеек (F1–F5);
- intent-score < 0.2 (мало «готов попробовать первым» / целевого ответа);
- в микро-вопросе доминирует «просто интересно» / нецелевой мотив.
- **Кешбэк-ячейки (L3/L4):** raw-signup НЕ считаем победой — дисконтируем по intent-score.
- **Эксперимент (X1/X2):** kill-fast — выключаем первыми при дорогом CPS или низком интенте.

## Минимальная выборка
На ячейку — **≥100 заявок ИЛИ ≥3000 кликов** до выводов; иначе сигнал считаем шумом.
Результаты — относительный ранг офферов, не абсолютный спрос.

## Гипотезы (pre-registered — сверим на этапе 9)
- **H1:** S-ячейки (F1–F3) дают лучший quality-adjusted CPS.
- **H2:** Кешбэк (L3/L4) — самый высокий raw-signup, но самый большой разрыв signup↔интент.
- **H3:** AI-power (X1/X2) — низкий интент, выключаются рано.
- **H4:** O5 (корп, нет альтернативы) — лучший интент внутри A.
- **H5:** O2 (детское) — высокий CTR, но интент-флаг (эмоция).
- **H6:** Директ-поиск даёт лучший интент (горячий запрос), VK/TG — дешевле клик, но больше «любопытных».

## Выход (этап 9)
Сводим факт против H1–H6: какой **оффер × аудитория × площадка** дал лучшие
quality-adjusted заявки → на это фокусируем продукт и первый маркетинг. Материалы ячеек —
в [`targeting/`](targeting/), [`creatives/`](creatives/), [`landings/`](landings/).
