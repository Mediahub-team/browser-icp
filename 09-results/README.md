# Этап 9 — Результаты и выводы

Метрики открутки + ответ на главный вопрос: **какой оффер на какую аудиторию заходит
лучше всего**. Имя: `results-<date>.md`. Шаблон: [`../templates/results-template.md`](../templates/results-template.md).

**Вход:** кампании (`08-ads/`) + аналитика (AppMetrica: установки→онбординг→активация).
**Выход:** решения о масштабировании/выключении связок + уточнённые гипотезы на следующую итерацию.

### Что делаем
1. Сводим метрики (CTR, CPI/CPA, конверсия в активацию, ROMI) по связкам оффер × аудитория × площадка.
2. Строим матрицу «оффер × аудитория» (где работает / средне / провал).
3. Сверяем факт с гипотезами этапа 8 — что подтвердилось, что перевернулось.
4. Победившие связки → в Core-кольцо ICP; провальные офферы — дорабатываем/убираем.
5. **Харвест петли 7→0:** из победивших офферов собрать кандидатные возможности (поле
   «Подразумеваемая возможность») → в `version/` следующей функциональности ([`../BRANCHING.md`](../BRANCHING.md) §4).
6. Формулируем следующий раунд (→ этапы 1/7) и вопросы для живого CustDev.
