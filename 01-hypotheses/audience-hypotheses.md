# Гипотезы аудиторий — Кэшбэк Браузер

**Источники:** [[product-description]] (этап 0).

> Стартовый набор сегментов-кандидатов из описания продукта. Это **черновик для
> приоритизации**, а не истина — каждый скоринг проверяется в интервью (этапы 5–6) и
> рекламе (этап 9).
>
> ⭐ **Версия 2 (после фидбека):** продукт несёт **три ценности**, и ведущей для разных
> сегментов будет разная:
> - **A — Универсальный ИИ-ассистент на любом сайте** (саммари, ответы по странице, веб-ресёрч). Ведущий пилар по оценке команды.
> - **S — Анти-обман / уверенность в выборе** (ИИ-анализ товара и продавца на маркетплейсах).
> - **C — Кешбэк / экономия** (возврат денег, сравнение цен).
>
> Поэтому добавлены assistant-led сегменты и введена ось мотива. Скоринг fit-confidence
> (0–100) — взвешенная оценка по осям ниже.

## Оси и веса (v2)
| Ось | Вес | Что оцениваем |
|---|---|---|
| Problem fit | 0.28 | есть ли острая боль (шопинг ИЛИ «много читаю/ищу, нет времени вникать») |
| Value fit | 0.28 | насколько A/S/C закрывают именно его боль |
| Engagement/частота | 0.18 | как часто возникает повод (покупки ИЛИ чтение/поиск) — драйвер удержания и LTV |
| Reachability | 0.16 | доступность через VK/Директ/TG, понятный таргет |
| Adoption barrier | 0.10 | штраф за барьер «поставить отдельный браузер» и конкуренцию (родные браузеры, standalone-ИИ) |

> Для каждого сегмента указываем **ведущий мотив (A/S/C)** — он определяет угол оффера.

## Assistant-led сегменты (мотив A)

### H1. AI-power-users / ранние адопторы ИИ
Уже пользуются ChatGPT/Алисой/Gigachat, любят инструменты и автоматизацию, кайфуют от
агента, который «видит» страницу. Мотив — **A** (контроль/эффективность).
- Problem fit: средний-высокий · Value fit: высокий (ассистент в контексте страницы — то, чего нет у standalone-чатов) · Engagement: высокий (юзают ИИ ежедневно) · Reach: средний (TG-каналы про ИИ, YouTube, Хабр) · Adoption: средний (любят пробовать новое).
- **Fit ≈ 78.** Евангелисты и источник фидбека. Ключевая отстройка для них: «ИИ прямо на той странице, что открыта», а не очередной чат. Риск: требовательны к качеству модели, малочисленны.

### H2. Контент-потребители / читатели на ходу
Много читают с телефона: Telegram-каналы, новости, лонгриды, обзоры. Боль — «слишком
много текста, нет времени вычитывать». Мотив — **A** (саммари, «дай суть»).
- Problem fit: высокий · Value fit: высокий (саммари ленты/статьи, ответы по странице) · Engagement: очень высокий (читают ежедневно) · Reach: высокий (TG, новостные паблики VK) · Adoption: средний-низкий (надо открыть страницу именно в нашем браузере).
- **Fit ≈ 76.** Большой и достижимый сегмент, высокая частота. Главный барьер — привычка читать в Telegram/Safari; нужен повод открывать ссылки у нас (тут помогает share-extension «Открыть в Кэшбэк Браузере»).

### H3. Студенты и самообучающиеся
Учатся, делают ресёрч, разбираются в темах. Боль — быстро понять/сравнить/объяснить.
Мотив — **A** (объяснение, ресёрч), вторично **C** (цена — чувствительны).
- Problem fit: высокий · Value fit: высокий (объясни/сравни/саммари + веб-поиск) · Engagement: высокий · Reach: высокий (VK, TG, дешёвый трафик) · Adoption: средний.
- **Fit ≈ 72.** Дешёвый трафик, высокая частота использования ассистента; низкий шопинг-чек, зато сильный A-мотив и потенциал «привычки».

### H4. Занятые профи знаниевого труда (мобильное чтение)
Маркетологи, продакты, аналитики, журналисты — на ходу читают статьи/каналы, нужен
быстрый разбор и ресёрч с телефона. Мотив — **A** (экономия времени).
- Problem fit: высокий · Value fit: высокий · Engagement: высокий · Reach: средний (TG проф-каналы, LinkedIn-замены, нишевый таргет) · Adoption: низкий-средний (на десктопе у них свои инструменты).
- **Fit ≈ 66.** Сильная ценность, но мобильный сценарий и барьер «ещё один браузер»; узкий таргет.

## Shopping-led сегменты (мотивы S/C)

### H5. Охотники за выгодой / экономные покупатели
Ищут промокоды, кешбэк, сравнивают цены. Мотив — **C** (экономия).
- Problem fit: высокий · Value fit: высокий (кешбэк+сравнение) · Engagement: высокий · Reach: высокий (кешбэк/купонные паблики) · Adoption: средний.
- **Fit ≈ 82.** Сильнейший shopping-ICP. Риск: требовательны к доверию выплат, конкуренция с Letyshops/Backit.

### H6. Тревожные / осторожные покупатели (боятся обмана)
Боятся накрутки отзывов, ненадёжных продавцов, подделок. Мотив — **S** (уверенность/контроль).
- Problem fit: высокий · Value fit: высокий (ИИ-оценка 0–10, анализ продавца) · Engagement: средний · Reach: средний · Adoption: средний.
- **Fit ≈ 79.** Ведущий угол — «не купить плохое», кешбэк вторичен. Хорошо стыкуется с A (тот же ассистент «проверь этот товар»).

### H7. Частые покупатели маркетплейсов (heavy users Ozon/WB)
Заказывают еженедельно, большой объём. Мотив — **C** + **S** (деньги + время).
- Problem fit: средний-высокий · Value fit: высокий · Engagement: очень высокий · Reach: высокий · Adoption: средний (привычка к родным приложениям МП).
- **Fit ≈ 80.** Высокий LTV-потенциал; барьер — родные приложения Ozon/WB.

### H8. Семейные закупщики (родители, бытовые покупки)
Регулярные закупки на семью, считают бюджет, ценят надёжность. Мотив — **C** + **S**.
- Problem fit: высокий · Value fit: высокий · Engagement: высокий · Reach: средний (VK, родительские сообщества) · Adoption: средний-низкий (консервативны).
- **Fit ≈ 74.** Сильный экономия + анти-риск; барьер — недоверие к новому софту.

### H9. Молодёжь 18–25, мобильные и визуальные
TikTok/Telegram/VK, импульсивные покупки, чувствительны к цене, открыты к ИИ. Мотив — **C** + **A**.
- Problem fit: средний · Value fit: средний-высокий (кешбэк, колесо, геймификация + ИИ как «вау») · Engagement: средний · Reach: очень высокий · Adoption: средний.
- **Fit ≈ 70.** Дешёвый трафик, но низкий чек и доверие; хорош для геймифицированных и A-«вау» офферов.

## Вторичные / контраст

### H10. Перекупы / реселлеры / закупка для бизнеса
Покупают для перепродажи, анализ продавца и цены — рабочий инструмент. Мотив — **S** + **C**.
- **Fit ≈ 65.** Высокая ценность, но узко и сложно таргетировать.

### H11. Пенсионеры / 55+ онлайн-покупатели
Осваивают маркетплейсы, боятся обмана, нужна простота. Мотив — **S**.
- **Fit ≈ 45.** Сильная боль (страх обмана), но высокий барьер установки и низкая досягаемость → Peripheral/Non-ICP.

## Предварительный ранг для проработки в ICP (этап 2)

**По fit-скору (go-to-market прагматика):**
1. **H5 Охотники за выгодой** (82) — мотив C
2. **H7 Частые покупатели МП** (80) — C+S
3. **H6 Тревожные покупатели** (79) — мотив S
4. **H1 AI-power-users** (78) — мотив A
5. **H2 Контент-потребители** (76) — мотив A
6. **H8 Семейные закупщики** (74) — C+S
7. **H3 Студенты** (72) — мотив A

**Стратегическая поправка (фидбек команды).** Ассистент (мотив A) — ведущая ценность
продукта и сильнейшая отстройка, поэтому **обязательно проводим в проработку минимум
2 assistant-led сегмента** (H1 + H2), даже если их fit чуть ниже shopping-лидеров.
Гипотеза: A-аудитория хуже «считается» классическим shopping-скорингом, но даёт
уникальную, незанятую конкурентами ценность и высокую частоту использования (драйвер
привычки и удержания).

**Рекомендация — взять в этап 2 сбалансированный набор по мотивам:**
- мотив A: **H1, H2** (+ H3 как кандидат)
- мотив S: **H6**
- мотив C: **H5** (+ H7 как heavy-user)

## Риски и развилки для проверки
- **A vs S vs C — что реально заводит на установку?** Главная развилка интервью/рекламы.
- **Барьер «ещё один браузер».** Для A-сегментов конкурент — standalone ChatGPT/Алиса;
  наша отстройка = «ИИ на той странице, что открыта» + share-extension. Проверить, достаточно ли этого.
- **Доверие к выплате кешбэка** — ключевое возражение C-сегментов (H5/H7).
- **Повод открывать ссылки в нашем браузере** (для H2/H4) — без него assistant-ценность не активируется.

> ⚠️ Скоринг — экспертная гипотеза LLM, не данные. Цель этапов 2–6 — подтвердить/перевернуть,
> особенно силу assistant-led сегментов относительно shopping-лидеров.
