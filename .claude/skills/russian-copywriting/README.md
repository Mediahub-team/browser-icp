# russian-copywriting

**Наш скилл** (custom). Продающий текст на **живом русском** для RU-рынка: без канцелярита,
штампов и калек с английского, по ФЗ-38. Определение — [`SKILL.md`](SKILL.md).

## Зачем
Англоязычный `copywriting` + `stop-slop` не ловят главные пороки русского текста (канцелярит,
кальки, «Вы»-официоз) и ошибочно режут русское тире. Этот скилл = их принципы конверсии/чистки
**плюс русский слой**.

## Состав
- [`SKILL.md`](SKILL.md) — порядок работы (контекст+гейт → «ты/вы» → текст → stop-slop с поправкой §4 → русский чек-лист → ФЗ-38).
- [`references/ru-slop.md`](references/ru-slop.md) — каталог русского слопа с заменами (канцелярит, кальки, штампы, ложные усилители).
- [`references/ru-market.md`](references/ru-market.md) — тон RU-рынка, «ты/вы/Вы», ФЗ-38, маркировка erid, площадки и char-лимиты.

## Ключевые решения адаптации
- **Канцелярит** — главный враг (отглагольные сущ., «является/осуществляется/данный»); англо-слоп его не видит.
- **Тире (—) сохраняем** — нормальная русская пунктуация (правило stop-slop «убрать тире» отменено).
- **ФЗ-38** в гейте: «лучший/№1/гарантированно/100%» и связывающие цифры — запрещены.
- **Customer language** — сырьё в кавычках, не готовый слоган.

## Где используется
Этап 8 — обязателен для всех формулировок (креативы, лендинги, таргеты), см.
[`../../../08-ads/README.md`](../../../08-ads/README.md) «Скиллы этапа». Композится с `ad-creative`/`ads`
(структура) и `stop-slop` (построчная чистка). Переиспользуем и вне этапа 8.
