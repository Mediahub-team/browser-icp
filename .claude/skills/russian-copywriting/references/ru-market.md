# RU-рынок: стиль, право, площадки

## 1. Тон российского веб-копирайтинга

- **Скепсис к рекламе высокий.** Громкие обещания, восклицания, КАПС → недоверие. Работают
  конкретика, пруфы, «как это работает», отзывы с деталями.
- **Доказательство > эмоция.** «Покажи, не рассказывай»: скрин, цифра, шаг, а не «лучший сервис».
- **Современный веб ушёл от официоза.** «Вы» с прописной и канцелярит = «сайт из 2010». Живой
  разговорный тон («ты»/строчное «вы») выигрывает у молодой и массовой аудитории.
- **Юмор и самоирония** уместны у casual-брендов, но не ценой ясности.

## 2. «Ты» / «вы» / «Вы» — расширенно

- **ты** — соцсети (VK, Telegram), tech, стартапы, 18–35, casual. Дружеский, на равных.
- **вы** (строчная) — дефолт для веба и массового рынка. Уважительно и современно.
- **Вы** (прописная) — только формальный B2B / юр-тексты / старшая консервативная аудитория.
  В продающем вебе почти всегда воспринимается как канцелярит — избегать.
- Никогда не смешивать обращения внутри одного текста/воронки.

## 3. Закон «О рекламе» (ФЗ-38) — что нельзя

- **Превосходная степень без подтверждения (ст. 5):** «лучший», «№1», «самый выгодный»,
  «лидер рынка», «гарантированно», «100%», «навсегда» — запрещены без документальных пруфов.
- **Некорректные сравнения** с конкурентами («лучше, чем X») — риск.
- **Финансовые/кешбэк-обещания:** не сулить фиксированную доходность/процент без условий и
  оговорок; «до X%» требует пояснения условий.
- **Достоверность:** выдуманные отзывы, несуществующие скидки («было/стало» с накруткой) —
  нарушение и репутационный риск.

## 4. Маркировка интернет-рекламы (с 2022)

- Платные размещения: пометка **«Реклама»**, указание рекламодателя, токен **erid** через ОРД
  (оператор рекламных данных).
- Это требование к **размещению/ТЗ**, не к тексту хедлайна — учитывать в брифе кампании, не
  зашивать в сам продающий заголовок.

## 5. Площадки и лимиты

| Площадка | Роль | Лимиты текста |
|---|---|---|
| **Яндекс Директ — Поиск** | горячий intent | Заголовок-1 ≤ 56, Заголовок-2 ≤ 30, Текст ≤ 81 |
| **Яндекс Директ — РСЯ** | demand-gen, ретаргет | те же + изображение |
| **VK Ads** | охват по сообществам/интересам | короткий заголовок ~ 40, текст варьируется по формату |
| **Telegram Ads** | контекст каналов | текст ≤ 160, без внешней картинки в TG Ads |
| **Дзен** | нативные статьи/охват | заголовок-зацепка + лонгрид |

Не ссылаться на заблокированные/экстремистские в РФ площадки и бренды.

## 6. Деньги и единицы

- Рубли: «199 ₽», «от 0 ₽», «₽» после числа с неразрывным пробелом.
- Даты/числа по-русски: «10 июня», «1 000 000» (пробел-разделитель разрядов), не «1,000,000».
- Кавычки — «ёлочки» в основном тексте, „лапки“ для вложенных.

## 7. Мини-пример (до / после)

**До (канцелярит + штамп + калька):**
> Наш инновационный сервис представляет собой решение для осуществления возврата денежных
> средств. Мы предлагаем индивидуальный подход и выгодные условия для каждого клиента!

**После (живой русский, «ты», под гейт):**
> Кешбэк ловится сам — за любой сайт, без захода через ссылки. Покупаешь как обычно, рубли
> возвращаются на баланс. Видно каждый шаг: начислили, подтвердили, вывели.
