# Русский слоп — что резать и на что менять

Дополняет `stop-slop` (английские паттерны) русскоязычными следами AI и плохого копирайтинга.
Источник идеала живого языка — Нора Галь, «Слово живое и мёртвое» (борьба с канцеляритом).

## 1. Канцелярит (главный враг)

Самый частый порок русского текста, и AI его обожает. Признак — отглагольные существительные,
безличные обороты, длинные цепочки родительного падежа.

| Канцелярит | Живой русский |
|---|---|
| осуществление возврата средств | возвращаем деньги |
| реализация функции / реализован функционал | работает, делает |
| обеспечение безопасности данных | защищаем данные |
| использование приложения позволяет | в приложении можно |
| является решением для | решает, помогает |
| представляет собой | это (или вырезать) |
| данный продукт / в данный момент | этот продукт / сейчас |
| в целях экономии | чтобы сэкономить |
| в связи с тем, что | потому что |
| на сегодняшний день | сегодня (или вырезать) |
| в кратчайшие сроки | быстро, за день |
| производится начисление кешбэка | начисляем кешбэк |

**Цепочки родительного:** «улучшение качества обслуживания клиентов компании» → «клиентам станет
удобнее». Если в фразе 3+ существительных в родительном подряд — переписать через глагол.

## 2. Throat-clearing (русские зачины-пустышки)

Резать, говорить сразу по делу.

- «Давайте разберёмся / поговорим о»
- «Стоит отметить, что» / «Хочется отметить»
- «Важно понимать, что»
- «Не секрет, что» / «Как известно»
- «В современном мире» / «В наше время» / «Сегодня всё больше людей»
- «В условиях современного рынка»
- «Нельзя не сказать о»
- «В этой статье мы рассмотрим» / «Сейчас расскажем»

## 3. Кальки с английского (AI-перевод наизнанку)

| Калька | По-русски |
|---|---|
| в конце дня (at the end of the day) | в итоге / в конечном счёте |
| на одной странице (on the same page) | договорились / поняли друг друга |
| двигаться вперёд (moving forward) | дальше / теперь |
| глубокое погружение (deep dive) | разбор / подробно |
| изменить правила игры (game-changer) | сильно меняет / важно |
| бесшовный (seamless) | без лишних шагов / незаметно |
| решение (solution) — для всего подряд | назвать конкретную вещь |
| опыт (experience) — «незабываемый опыт покупок» | покупки / как покупаешь |
| экосистема / синергия | назвать конкретику или вырезать |

## 4. Маркетинговые штампы (пустые, не верят)

Менять на конкретный факт.

- «широкий ассортимент» → «12 000 магазинов» (если правда)
- «выгодные / приятные цены» → конкретная цифра или вырезать
- «индивидуальный подход» → что именно делаете
- «команда профессионалов» → факт о команде или вырезать
- «высокое качество» → доказательство
- «инновационные решения» → что именно
- «надёжный партнёр» → пруф надёжности
- «гибкая система скидок», «всё для вашего удобства», «лидер рынка» → резать (а «лидер»/«лучший» ещё и противоречит ФЗ-38)

## 5. Ложные усилители (русские наречия-вата)

Удалять, как adverbs в stop-slop.

«просто», «реально», «очень», «крайне», «поистине», «по-настоящему», «буквально»,
«действительно», «на самом деле», «честно говоря», «как ни странно», «прямо», «вот прямо».

## 6. Ложные контрасты (русские версии binary contrast)

- «Дело не в X. Дело в Y.» → сказать Y прямо.
- «Это не просто X — это Y» → назвать Y.
- «Вопрос не в том, X, а в том, Y» → задать суть.
- «Не X, а Y» как механический разворот → утверждать Y.

## 7. Восклицания, КАПС, спам-сигналы

Российская аудитория скептична к рекламе. Восклицательные знаки, КАПС, «🔥СКИДКА🔥»,
«Успей!», «Только сегодня!» читаются как впаривание. Менять на спокойную конкретику и пруф.
Исключение — вопрос-зацепка без восклицания: «Надоело заходить через ссылку?» — работает.

## 8. Лишние местоимения (особенно притяжательные)

Проверь: удаляется ли местоимение без потери смысла? Чаще всего да.
- «Наша компания производит металлопрокат с 1990 года» → «“Металлстройплюс” производит металлопрокат с 1990 года».
- «Возврат идёт на твой баланс» → «Возврат идёт на баланс» (чей ещё).

Оставляй, **когда противопоставляешь своё и чужое** — там местоимение несёт смысл:
- «Ты не замечаешь своих ошибок, зато отлично видишь их у других.»

## 9. Усилитель прикрывает голую оценку

Усилитель («особое», «максимально») обычно подпирает **оценку без доказательства**. Сама оценка
не убеждает — работай с ней: дай факт или иллюстрацию.
- «Особое внимание мы уделяем качеству» → «Нам важно качество: проверяем каждую деталь на лазерном микроскопе».

## 10. Парцелляция — оставь художникам

Парцелляция — дробление одного предложения на куски ради интонации («Белая. Обычная белая
рубашка. Но любимая.»). В рекламе/информтексте интонацию не воспроизводим — работаем содержанием.
Признак: предложение синтаксически неполное, само по себе смысла не несёт.
- «Которая не скатывалась бы через пять минут.» → «Она не скатается за пять минут.»
- «А броско, шикарно и выделяла бы из толпы.» → «Она броская, шикарная и выделяет из толпы.»

Цель: каждое предложение **автономно, осмысленно, несёт новую информацию**. Если для этого
приходится начать с местоимения — это лучше, чем обрубок.

## 11. «Это» после тире обычно убирается

- «Кешбэк — это возврат части денег за покупку» → «Кешбэк — возврат части денег за покупку».
- «Лист ожидания — это очередь на ранний доступ» → «Лист ожидания — очередь на ранний доступ».

## Быстрый прогон

1. Есть отглагольное существительное, где можно глагол? — заменить.
2. Есть «является / данный / осуществляется / в целях»? — вырезать/переписать.
3. Есть калька (в конце дня, бесшовный, решение-для-всего)? — на русское.
4. Есть штамп (широкий ассортимент, индивидуальный подход)? — на факт.
5. Есть «просто/очень/реально/на самом деле»? — удалить.
6. Восклицания/КАПС? — убрать.
7. Тире НЕ трогать — это правильный русский (в отличие от правила stop-slop).
8. Притяжательное местоимение («наш/твой/свой») — удаляется без потери смысла? Удалить (кроме противопоставления своё/чужое).
9. Усилитель подпирает оценку? — заменить оценку фактом/иллюстрацией.
10. Парцелляция (обрубленные предложения ради интонации)? — собрать в автономные осмысленные.
11. «Это» сразу после тире? — почти всегда убрать.
