# web-design-guidelines

**Вендорный скилл** (автор — Vercel). Ревью UI-кода на соответствие Web Interface Guidelines:
доступность, UX, лучшие практики. Определение — [`SKILL.md`](SKILL.md).

## Что делает
Подтягивает свежие гайдлайны из источника, читает указанные файлы и выдаёт находки в кратком
формате `file:line`. Аргумент — файл или паттерн (`argument-hint: <file-or-pattern>`).

> Требует сети: правила фетчатся при каждом ревью (см. `SKILL.md` → Guidelines Source). В
> headless/cron-прогонах без сети работать не будет.

## Где может использоваться в проекте
**По запросу**: аудит собранного лендинга перед запуском (a11y/UX). В обязательный набор этапа 8
**не входит** (см. [`../README.md`](../README.md)). Естественная пара — после `frontend-design`.
