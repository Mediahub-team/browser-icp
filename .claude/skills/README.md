# Локальные скиллы проекта (`.claude/skills/`)

Скиллы, установленные **в репозитории** (видны через Skill-тул после `/reload-skills`).
Маркетинговые скиллы (`ads`, `ad-creative`, `cro`, …) живут не здесь, а в плагине
`marketing-skills` (кэш плагинов), и в репозиторий не вендорятся.

| Скилл | Источник | Назначение | Где в пайплайне |
|---|---|---|---|
| [`russian-copywriting`](russian-copywriting/) | **наш** (custom) | продающий текст на живом русском (RU-рынок): без канцелярита/штампов/калек, по ФЗ-38 | этап 8 — **обязателен** для всех формулировок (креативы, лендинги, таргеты) |
| [`stop-slop`](stop-slop/) | вендор (Hardik Pandya) | чистка прозы от AI-следов | основа `russian-copywriting` (англо-слой); общая правка текста |
| [`frontend-design`](frontend-design/) | вендор | сборка отличающихся production-grade веб-интерфейсов | сборка живой страницы из ТЗ-лендинга (по запросу; не встроен в регуляцию) |
| [`web-design-guidelines`](web-design-guidelines/) | вендор (Vercel) | ревью UI-кода на гайдлайны/доступность | аудит лендинга перед запуском (по запросу; не встроен) |

## Что встроено в этап 8 (обязательный шаг)
Регуляция этапа — [`../../08-ads/README.md`](../../08-ads/README.md) «Скиллы этапа». Обязательны:
`russian-copywriting` (локальный, здесь) + `ads` · `ad-creative` · `image` · `video` · `ab-testing`
(из плагина `marketing-skills`, адаптируются под RU). Принцип: **скилл предлагает — гейт решает**.
`frontend-design`/`web-design-guidelines` доступны, но в обязательный шаг **не входят**.

## Структура скилла
`<name>/SKILL.md` — определение (frontmatter `name`/`description` + инструкции). Опционально
`references/*.md` (подгружаемые материалы), `README.md` (эта документация), `LICENSE` (для вендорных).

## Обновление
После добавления/правки скилла — `/reload-skills`, иначе Skill-тул его не увидит.
