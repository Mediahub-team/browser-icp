# frontend-design

**Вендорный скилл** (лицензия — [`LICENSE.txt`](LICENSE.txt)). Сборка отличающихся,
production-grade веб-интерфейсов без «AI-slop»-эстетики. Определение — [`SKILL.md`](SKILL.md).

## Что делает
По требованиям (компонент/страница/приложение) выдаёт рабочий код (HTML/CSS/JS, React, …) с
чёткой эстетической позицией: типографика, цвет/тема, motion, композиция, фактуры. Избегает
шаблонных решений (Inter/Roboto, фиолетовые градиенты, предсказуемые лейауты).

## Где может использоваться в проекте
**По запросу**, не как обязательный шаг: сборка **живой страницы из ТЗ-лендинга**
([`../../../08-ads/landings/`](../../../08-ads/landings/), шаблон `landing-designer-brief`).
В обязательный набор этапа 8 **не входит** (см. [`../README.md`](../README.md)).

> Если соберём страницу этим скиллом — тексты берём из `russian-copywriting`, а не пишем заново
> в коде; затем прогон `web-design-guidelines` на доступность/гайдлайны.
