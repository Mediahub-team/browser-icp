## 4.1 Вердикт по kill-кандидатам (правило двух ключей)
> Здесь выносится **второй ключ**: kill-кандидаты этапа 0 ([[market-landscape]] §11) подтверждаются или
> опровергаются — **на ответах членов целевого сегмента**, не на агрегате ([[PLAN]] §2, Этап 1).
- По каждому kill-кандидату: **подтверждён / опровергнут / не разрешён** — на каких сегментах, с какой силой сигнала.
- **Выжила ли ниша** (оговорка выживания): нашлись ли респонденты, для кого барьера нет → угол жив в нише N.
- **Killed** — только при конъюнкции (рынок §0 ландшафта **И** интервью здесь). Иначе — деприоритизация, не приговор.
