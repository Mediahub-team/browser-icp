# Промт для AI-генерации лендинга — <оффер / ICP-NN>

> Готовый промт для сервиса генерации дизайна/кода. **Главный таргет — Claude (Artifacts)**;
> ядро универсальное (подойдёт v0/Lovable/Bolt/любой LLM). Заполни плейсхолдеры `<…>` из
> оффера (`07-offers/`), спека лендинга (`08-ads/landings/<seg>.md`), описания продукта
> (`00-product/product-description.md`) и customer language ICP (`02-icp/`), затем вставь
> блок «ПРОМТ» целиком в сервис.

## Как пользоваться
1. Заполни плейсхолдеры в блоке ПРОМТ. 2. Вставь в Claude (или иной сервис). 3. Получишь
адаптивный лендинг одним файлом. 4. Проверь по чек-листу внизу.

---

## ПРОМТ (копировать целиком)

```
Ты — продуктовый веб-дизайнер и фронтендер. Сделай ОДНОСТРАНИЧНЫЙ адаптивный лендинг
(mobile-first) одним самодостаточным файлом: HTML + Tailwind (CDN) + минимум JS.
Никаких внешних зависимостей кроме Tailwind CDN. Верни один файл, готовый открыть в браузере.

КОНТЕКСТ ПРОДУКТА (пред-запуск, продукт ещё не вышел):
<1–2 фразы из product-description: что за продукт, ведущая ценность>.
ЧЕСТНОСТЬ (обязательно соблюдать, не приукрашивать): <напр. «глубокий разбор товара пока
только на Ozon», «кешбэк без конкретных %/сроков»>.

ЦЕЛЬ СТРАНИЦЫ: единственное целевое действие — оставить заявку в ЛИСТ ОЖИДАНИЯ (e-mail).
Продукт ещё не запущен — не предлагай «скачать приложение».

АУДИТОРИЯ И ТОН: <ICP-NN, мотив A/S/C; tone — напр. спокойный/честный или простой «механика, не интеллект»>.
ЯЗЫК (вставь дословно в тексты): «<фраза 1>», «<фраза 2>», «<фраза 3>».
СЛОВА-ТАБУ (не употреблять): <успей/скидка/выгодно | нейро/LLM/агент/тул>.

СТРУКТУРА (сверху вниз):
1. Hero: H1 = «<главный посыл оффера>»; подзаголовок = «<механика/обещание>»; кнопка CTA «Записаться в лист ожидания».
2. Три буллета ценности: <буллет 1>; <буллет 2>; <буллет 3>.
3. Demo-блок: визуально покажи «<как работает>» (схематичная иллюстрация/мокап, без фото-стоков).
4. Блок доверия: <на чём вердикт / независимость / честная граница>.
5. Форма waitlist: поле e-mail + кнопка. ПОСЛЕ отправки показать intent-блок:
   - вопрос «Что для вас главное?» с вариантами: <вариант под оффер>, <ещё>, <контрольный «кешбэк»>;
   - чекбокс «Готов попробовать первым и оставить отзыв».
   (JS: по сабмиту прятать форму, показывать intent-блок и «спасибо»; данные никуда не шлём — заглушка.)
6. Лёгкое соц.доказательство (плейсхолдеры) + короткий футер.

ДИЗАЙН: mobile-first, чистая типографика, <палитра/настроение>. Без таймеров, без «осталось N мест»,
без давления. Доступность (контраст, размеры тапа). Семантический HTML.

ИЗМЕРЕНИЕ (заглушки, без реальных ключей): предусмотри место под цель Метрики «waitlist_signup»
(data-атрибут на форме) и чтение UTM из URL.

Верни ТОЛЬКО код одного файла.
```

## Чек-лист после генерации
- [ ] CTA = «лист ожидания», нет «скачать приложение».
- [ ] Нет слов-табу; использован customer language.
- [ ] Есть intent-блок после заявки (микро-вопрос + чекбокс).
- [ ] Соблюдены честность-констрейнты (Ozon-only, кешбэк без цифр).
- [ ] Mobile-first, адаптивно, без давления/таймеров.

**Источники** (подставить реальные вики-ссылки при заполнении): спек лендинга `08-ads/landings/<seg>`, оффер `07-offers/offer-<...>`, ICP `02-icp/icp-NN-...`, `00-product/product-description`.
