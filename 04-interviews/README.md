# Этап 4 — Сценарии интервью

Несколько вариантов гайдов на базе six-pillar каркаса.
- [`custdev/`](custdev/) — про продукт, ценность, adoption, WTP. Шаблон: [`../templates/interview-custdev-template.md`](../templates/interview-custdev-template.md).
- [`problem/`](problem/) — про боль и текущие решения, **без упоминания продукта** (JTBD/Mom Test). Шаблон: [`../templates/interview-problem-template.md`](../templates/interview-problem-template.md).

**Варианты делать осмысленными**, а не косметическими: разный фокус (acquisition vs
retention), длина (10 vs 30 мин), тон, набор форматов ответов. Имя: `guide-v1.md`, `guide-v2.md`.

### Промпт генерации
> Составь гайд интервью по соответствующему шаблону. Сохрани каркас six pillars, чтобы
> ответы сравнивались между сегментами. Вопросы — не наводящие, про прошлый опыт и
> факты. Смешай форматы (Likert/числовые/выбор/открытые). Сделай N вариантов с разным
> фокусом и поясни, что проверяет каждый.
