# Этап 5 — Прогон интервью на портретах

40 синтетических респондентов по fit-кольцам (Core 16 / Strong 12 / Peripheral 8 /
Non-ICP 4) отвечают «в роли» персон на гайды этапа 4. Каждый прогон — в подпапку
`run-<guide>-<date>/` (транскрипты + сводная таблица). Шаблон:
[`../templates/simulation-run-template.md`](../templates/simulation-run-template.md).

**Вход:** персоны (`03-personas/`) + гайды (`04-interviews/`).
**Выход:** структурированные ответы для анализа (этап 6).

### Промпт прогона
> Сгенерируй 40 респондентов по распределению fit-колец. Каждый отвечает от первого лица
> в характере своей персоны (мотив, доход, барьеры, язык), реалистично — с сомнениями и
> отказами. Не подыгрывай интервьюеру; у Peripheral/Non-ICP закладывай скепсис.
> **Отвечай ТОЛЬКО из личного поведения персоны** (её реальные каналы/площадки/программы) —
> **не** из рыночной статистики и «как делает большинство»: если персона сама так не делает, у неё
> нет этого мнения; где не сталкивалась — так и скажи. Включи **дисконфирм-сэмпл** — респондентов,
> чьё реальное поведение **противоречит** агрегату (не-МП-покупатель, browser-native), чтобы вскрыть
> нишу, а не штамповать среднее (анти-grounding-echo, [`../CALIBRATION.md`](../CALIBRATION.md) ось 2).
> Likert — число 1–5, числовые — конкретику, открытые — 1–3 предложения языком персоны. Сложи
> ответы в сводную таблицу по 6 pillar'ам + сохрани сильные цитаты. После прогона — калибровка
> по двум осям (демо-прайминг + grounding-echo).
