# Этап 3 — Портреты пользователей (персоны)

Детальные живые персоны по 8 B2C-компонентам, 1–2 на каждый ICP. Имя файла
`persona-<icp>-<name>.md`. Шаблон: [`../templates/persona-template.md`](../templates/persona-template.md).

**Вход:** ICP из `02-icp/`. **Выход:** персоны, готовые служить «ролью» в синтетических
интервью (этап 5).

### Промпт генерации
> На основе ICP-файла создай 1–2 детальные персоны по шаблону
> `templates/persona-template.md`. Конкретный человек: имя, возраст, город, день из
> жизни, дословные цитаты. Тащи только то, что влияет на установку браузера, доверие к
> кешбэку, поведение на маркетплейсах и реакцию на офферы. Укажи fit-кольцо. Внутри
> одного ICP делай персоны разными (возраст/доход/опыт), чтобы покрыть вариативность.
> **Обязательно** заполни «Фактическое поведение (якорь ответов)» — конкретные реальные каналы/
> площадки/программы персоны: это якорь, из которого она отвечает в интервью, а **не** рыночный
> агрегат (анти-grounding-echo, [`../CALIBRATION.md`](../CALIBRATION.md) ось 2).
