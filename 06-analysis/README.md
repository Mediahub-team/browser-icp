# Этап 6 — Анализ

Интерпретация ответов: pillar-скоринг по сегментам, кросс-сегментные паттерны, темы,
validated/untested, ранжирование ICP, messaging-углы и гипотезы каналов. Имя:
`analysis-<date>.md`. Шаблон: [`../templates/analysis-template.md`](../templates/analysis-template.md).

**Вход:** прогоны (`05-simulations/`). **Выход:** executive summary + входные данные для офферов (этап 7).

### Промпт анализа
> Проанализируй сводные ответы прогона по шаблону `templates/analysis-template.md`.
> **Сначала калибровка сигнала** (до интерпретации): ось 1 — демо-прайминг (Δ custdev vs problem),
> ось 2 — grounding-echo (индивидуация vs эхо агрегата); контаминированные прогоны — на перегон, не
> в анализ ([`../CALIBRATION.md`](../CALIBRATION.md)). Посчитай средние по pillar'ам × ICP, подсвети
> сильнейшие/слабейшие измерения, выдели повторяющиеся темы с частотой и цитатами, раздели
> validated/untested/опровергнуто. **Вынеси вердикт по kill-кандидатам этапа 0 (правило двух ключей):**
> подтверждены/опровергнуты **на членах сегмента** (не на агрегате); выжила ли ниша; «killed» — только
> при конъюнкции рынок+интервью. Отранжируй ICP, сформулируй messaging-углы и гипотезы каналов. Дай
> краткое executive summary с первичным ICP и следующими вопросами для живого CustDev.
