# Оффер — «ИИ без Яндекса» (ICP-04, угол: privacy/анти-Яндекс)

> Первичный сегмент по ревизии ранга ([[comparison-2026-06-23]] §5): единственная ниша, проходящая
> KA+KB. Уважает инварианты (iOS, только в браузере); кешбэк не упоминается.

- **ICP / аудитория:** [[icp-04-privacy-antiyandex]] — приватность-сознательные, отвергающие Яндекс-экосистему.
- **Боль/триггер:** «нужен удобный ИИ по странице, но единственный встроенный в РФ — Алиса, а это Яндекс».
- **Ведущий мотив:** контроль / приватность.
- **Главный посыл:** «ИИ в браузере — **без Яндекса**. Видит твою страницу, отвечает со ссылками — и не тянет тебя в чужую экосистему.»
- **Выгода:** удобство «ИИ видит экран» без логина в Яндекс/большую экосистему; на русском, без VPN.
- **Доказательство:** прозрачная политика данных; ассистент работает только в этом браузере; ответы со ссылками.
- **CTA:** «Поставить ИИ-браузер без Яндекса».
- **Формат-кандидат:** текст/статика для нишевых каналов; скепсис к хайпу.
- **Гипотеза:** зайдёт лучше всего там, где Яндекс — стоп-фактор; KA низкий (уже меняют браузеры).
- **Метрика успеха:** CTR в нишевых каналах · конверсия в установку · доля «по причине приватности».
- **Подразумеваемая возможность:** **верифицируемая приватность/без-трекинга** как явная фича
  (политика + техническая гарантия) — кандидат в §7 следующей версии функциональности (петля 7→0).

## Варианты заголовков (для A/B)
1. «ИИ, который видит твою страницу — без Яндекса».
2. «Умный браузер без слежки и без экосистемы».
3. «Спроси ИИ прямо на странице. На русском, без VPN, без Яндекса».
