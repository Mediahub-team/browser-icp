# Оффер — «Свести вкладки в ответ со ссылками» (ICP-03, угол: ресёрч)

> Вторичный сегмент ([[comparison-2026-06-23]] §5). Боль пере-формулирована калибровкой: не «копир.»,
> а сведение источников + ссылки. Multi-tab — здесь ведущая ценность (в палитре её нет → петля 7→0).

- **ICP / аудитория:** [[icp-03-knowledge-workers]] — аналитики/консультанты, ресёрч с телефона.
- **Боль/триггер:** «открыто 5 вкладок, надо свести в вывод со ссылками — а с телефона мучение».
- **Ведущий мотив:** контроль над информацией / уверенность в выводе.
- **Главный посыл:** «**Свести несколько вкладок в один ответ — со ссылками на источники.** Прямо с телефона.»
- **Выгода:** готовый структурированный вывод из нескольких источников, не выходя из браузера; ссылки для перепроверки.
- **Доказательство:** ответы со ссылками на каждую вкладку; приватность рабочих данных (вне Яндекса).
- **CTA:** «Попробовать ресёрч по вкладкам».
- **Формат-кандидат:** демо-видео «5 вкладок → один ответ»; текст для деловых каналов.
- **Гипотеза:** зайдёт тем, кто реально ресёрчит с телефона; десктоп-привычка — барьер (KA).
- **Метрика успеха:** CTR · установка · доля multi-tab-запросов · возврат в рабочие дни.
- **Подразумеваемая возможность:** **сведение информации по нескольким вкладкам** — сегодня вне
  сборки ([[product-positioning]] §7), кандидат в §7 следующей версии функциональности (петля 7→0).

## Варианты заголовков (для A/B)
1. «Свести 5 вкладок в один ответ — со ссылками».
2. «ИИ-ресёрч по открытым вкладкам, прямо с телефона».
3. «Не копируй из вкладок — спроси по всем сразу».
