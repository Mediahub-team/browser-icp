# Этап 7 — Офферы

Офферы под сегменты на основе инсайтов этапа 6. Несколько вариантов оффера на сегмент
+ кросс-тест (один оффер на разные аудитории). Сводка — `offers-matrix.md` (оффер ×
сегмент), карточки — `offer-<slug>.md`. Шаблон: [`../templates/offer-template.md`](../templates/offer-template.md).

**Вход:** `06-analysis/`. **Выход:** офферы, готовые к запуску в рекламе (этап 8).

### Промпт генерации
> На основе messaging-углов и customer language из анализа сделай для каждого топ-ICP
> 2–3 варианта оффера по шаблону `templates/offer-template.md`. Каждый бьёт в конкретную
> боль/триггер, говорит языком клиента, содержит доказательство (особенно против
> возражения «обманут с кешбэком»). Добавь кросс-тест: какой оффер прогнать на другой
> аудитории. Собери матрицу «оффер × сегмент» с гипотезой, где зайдёт лучше.
