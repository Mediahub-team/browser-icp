# Матрица офферов × сегмент (v2) — 2026-06-05

> Вход: [[comparison-v2-2026-06-05]] (этап 6). Офферы под топ-ICP в порядке ревизованного
> ранга v2. Каждый бьёт в подтверждённую боль и **учитывает готовность сменить канал** —
> центральный фильтр v2. Все статусы — `untested`; проверяются рекламой (этап 8→9).

## Допущения v2
- 💰 **Юнит-экономика покрыта:** бизнес финансирует фикс-кешбэк (экономический гейт снят).
- ❗ **Только через браузер:** покупки/платежи вне браузера не выплачиваются (константа).
  Фильтр сегментов — готовность покупать/платить через браузер (лучший предиктор —
  прошлое канальное поведение).
- ❗ **UX-гейт:** покупка/платёж через браузер должны быть не медленнее привычного приложения,
  иначе app-bound сегменты не конвертятся.
- ⚠️ **Доверие к выплате:** бэкенд достраивается — без конкретных сумм/сроков.
- 🔒 **Лимит «один мерч/день»** — добросовестных не задевает (у них много разных мерчей).

## Приоритет запуска (этап 8)
1. **ICP-02 — [[offer-02-no-ritual]] + [[offer-02-payout-proof]].** Первичный: browser-native
   (барьер канала минимален), боль спонтанна, Ф бьёт в ритуал. Два угла — удобство vs пруф.
2. **ICP-01 — [[offer-01-every-purchase]] + [[offer-01-fix-plus-partner]].** Вторичный: уже
   меняют канал ради кешбэка; нужен охватный (эмоция) и расчётный (vs Letyshops) угол.
3. **ICP-04 — [[offer-04-family-budget]].** Третий: продавать возврат с покупок на сайтах;
   бытовое через браузер — бонусом, не обещанием.
4. **ICP-05 — [[offer-05-surprise-topup]].** Четвёртый, **ниша + UX-гейт**: только лайфхак-
   подтип (Кирилл), только при тривиальном переносе платежа в браузер.
- **ICP-03 (heavy-MP) — вне области цикла v2:** Δ_боли −1.8, не уходят из нативного приложения,
  покупка вне браузера. Вернуть только при продуктовом решении (заказ МП в браузере с UX не
  хуже приложения). В рекламный план **не входит**.

## Гипотезы кросс-тестов
- **«без ритуала» (02) → 01:** удобство vs охват у максимизаторов.
- **«со всего» (01) → 04:** охват vs бюджет-контроль у семейных.
- **«фикс+партнёр» (01) → 02:** не отпугивает ли расчётный тон тех, кому важна простота.
- **«плати через браузер» (05) → 04:** готовность сменить канал у лайфхакера vs семейного.
