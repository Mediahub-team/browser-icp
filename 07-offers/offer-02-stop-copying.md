# Оффер — «Перестань копировать в чат» (ICP-02, угол: поток работы)

> Третичный сегмент ([[comparison-2026-06-23]] §5). Боль копирования подтверждена калибровкой как
> реальная и ежедневная (✅, Влад). Риск — KB слаб (их эталон — платный ChatGPT) → проверяем качество модели.

- **ICP / аудитория:** [[icp-02-content-pros]] — SMM/копирайтеры/маркетологи, ИИ ежедневно.
- **Боль/триггер:** «весь день копирую куски в GPT, прыгаю между вкладкой и чатом, VPN отваливается».
- **Ведущий мотив:** экономия времени / поток.
- **Главный посыл:** «**Перестань копировать в чат** — ИИ видит открытую страницу. Спроси прямо здесь, ответ со ссылками.»
- **Выгода:** −десятки копипастов в день; без переключений; без VPN; ссылки для проверки фактов.
- **Доказательство:** демо «вопрос по странице без копирования»; ответы со ссылками.
- **CTA:** «Попробовать ИИ прямо в браузере».
- **Формат-кандидат:** демо-видео «−2 часа в день», кейс маркетолога.
- **Гипотеза:** зайдёт тем, у кого копирование — ежедневная рутина; риск — если модель слабее их ChatGPT.
- **Метрика успеха:** CTR · установка · частота вопросов-по-странице · удержание.
- **Подразумеваемая возможность:** нет (всё в палитре D — агент по странице + веб-поиск).

## Варианты заголовков (для A/B)
1. «Хватит копировать в GPT — ИИ видит твою страницу».
2. «ИИ прямо в браузере: без копипаста и без VPN».
3. «Спроси по странице, не выходя из неё».
