# Оффер — «Ловит сам, без ритуала» (ICP-03, угол: кешбэк за любую покупку через браузер)

**Источники:** [[comparison-2026-06-10]] (первичный ICP) · [[icp-03-cashback-optimizers]].

> Главный оффер первичного сегмента. Бьёт в подтверждённую болью без демо боль «ритуал переключения»
> (Δ≈0, активное поведение). Уважает инварианты [[product-functionality]] §2 (кешбэк только через
> браузер), не противоречит kill-вердиктам; модель вознаграждения — переменная (не зашиваем число).

- **ICP / аудитория:** кешбэк-оптимизаторы (агрегаторы + категории банка + промокоды), уже меняли канал/карту ради выгоды (K1-предиктор+).
- **Боль/триггер:** ритуал — заходить через спец-ссылку, проверять категорию, помнить промокод (этап 6, тема ×4).
- **Ведущий мотив:** контроль + самоутверждение («выжимаю максимум, но устал жонглировать»).
- **Главный посыл:** «Хватит жонглировать сервисами — покупай как обычно, кешбэк ловится сам за любой сайт.»
- **Выгода:** один браузер вместо зоопарка сервисов; кешбэк **за любой сайт** (не только партнёры), **стеком поверх банка** — без захода через ссылки.
- **Доказательство:** показываем авто-фиксацию покупки без партнёрской ссылки; прозрачный статус начисления; (для K3 — см. парный [[offer-03-payout-proof]]).
- **CTA:** «Поставь браузер — проверь на следующей покупке.»
- **Формат-кандидат:** видео (до/после ритуала) + карусель «сервис → один браузер».
- **Гипотеза:** зайдёт лучше всего на Core-оптимизаторов (Максим-тип); риск — посчитают ставку (K2) и сравнят со своим стеком.
- **Метрика успеха:** CTR в кешбэк-каналах; конверсия в установку → первая покупка через браузер; **доля дошедших до первого вывода** (момент доверия).
- **Подразумеваемая возможность (7→0):** **надёжный детект факта покупки на произвольном/нейтральном сайте без партнёрской ссылки** — повышение надёжности класса C палитры ([[product-functionality]] §3 C / §5 feasibility); кандидат в §7 следующей версии.

## Варианты заголовков (для A/B)
1. «Покупай как обычно — кешбэк ловится сам, за любой сайт.»
2. «Без захода через ссылки. Один браузер вместо пяти сервисов.»
3. «Твой стек кешбэка — и сверху ещё процент за любой сайт.»

## Кросс-тест
Прогнать на **ICP-01 web-native** (X1): для них «без ритуала» — слабее (у них ритуала и так нет), проверяем, цепляет ли «за любой сайт». Ожидание: слабее, чем на оптимизаторах — контроль чистоты позиционирования.
