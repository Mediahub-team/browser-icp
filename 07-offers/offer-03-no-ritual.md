# Оффер — «Ловит сам, без захода по ссылке» (ICP-02, угол: весь стек в одном браузере)

**Источники:** [[comparison-2026-06-15]] (вторичный, реформулирован) · [[icp-02-optimizers]].

> Вторичный оффер. **Калибровка оси 1 ([[comparison-2026-06-15]] §0): реальная боль сегмента — РИТУАЛ,
> не форма.** У оптимизаторов кешбэк не заперт (агрегаторы выводят), поэтому оффер строится на «ловит
> сам, без захода по ссылке», **не** на «живые рубли вместо баллов». Должен **бить стек** в рублях + пруф.

- **ICP / аудитория:** кешбэк-оптимизаторы (агрегатор + категории банка + промокоды), мигрируют ради выгоды (K1=100%).
- **Боль/триггер:** ритуал — «половину кешбэка теряю, забываю зайти по ссылке» (этап 6, ICP-02 спонтанно); ~5% заказов агрегатора в ручной запрос.
- **Ведущий мотив:** контроль + самоутверждение («выжимаю максимум, но устал жонглировать»).
- **Главный посыл:** «Весь твой стек кешбэка — в одном браузере. Ловит сам, без захода по ссылке.»
- **Выгода:** один инструмент вместо зоопарка; кешбэк за любой сайт + 5–15% на МП **без ритуала** захода через агрегатор.
- **Доказательство:** пруф вывода (они обжигались — «обещали 7%, дали 1,2%»); прозрачный статус; авто-фиксация без партнёрской ссылки.
- **CTA:** «Поставь браузер — сравни с тем, что выходит у тебя сейчас.»
- **Формат-кандидат:** Telegram кешбэк-каналы + посевы; разбор «было/стало» с цифрами; скрин механики.
- **Гипотеза:** зайдёт на Core-оптимизаторов (Максим-тип); риск — оставят нас **в стеке**, а не вместо.
- **Метрика успеха:** установка → **доля покупок, реально ушедшая к нам** (не «попробовал и бросил») → вывод.

## Офферная механика (без неё это угол, а не оффер)
- **Сценарная математика:** ~20 000 ₽/мес покупок на МП и сайтах. Текущий стек (агрегатор ~3% у
  партнёров + категория банка, но «протекает» ~половина из-за забытых ссылок) даёт ему по факту
  ~400–600 ₽/мес. Наш **5–15% на МП без ритуала** = **1 000–3 000 ₽** с той же корзины, **минус потери
  на забывании** (ловит сам). Дельта net против стека: **+400–2 000 ₽/мес**.
- **Модель вознаграждения — тест-варианты (условия пилота):** МП-тир **5–15%** + база за любой сайт
  (модель-переменная). Ключ для сегмента — **net против стека**, а не абсолют: оффер обязан показать
  «сколько сверх твоего текущего». Цифру тестируем (владелец утвердил вилку).
- **Возражение №1 и ответ:** «У меня уже связка — ты вместо чего-то или ещё одна вкладка? И выплатят
  ли?» → (1) дельта в рублях против его стека + «ловит сам, без забытых ссылок»; (2) **пруф вывода** —
  они недоверчивы после агрегаторов, без скринов выплат не поверят.
- **Risk reversal:** стек не ломает — ставит браузер параллельно, сравнивает по факту, оставляет если
  net положительный. «Проверь на следующих покупках — сам увидишь дельту».
- **Причина действовать сейчас:** ранний доступ + «зафиксируй повышенный пилотный % раньше остальных».
- **Подразумеваемая возможность (7→0):** надёжный детект на произвольном сайте без партнёрской ссылки ([[product-functionality]] §3 C) — ядро обещания «ловит сам»; кандидат в §7.

## Варианты заголовков (для A/B)
1. «Половину кешбэка теряешь, когда забыл зайти по ссылке? Браузер ловит сам.»
2. «Два агрегатора, три карты, промокоды — и всё равно мимо. Один браузер вместо стека.»
3. «Посчитай, сколько выходит у тебя. Потом посчитай с нами. Без захода по ссылкам.»
