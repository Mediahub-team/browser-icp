# Оффер — «Кешбэк без ритуала» (ICP-02, угол: ловит сам)

- **ICP / аудитория:** [[icp-02-cashback-disillusioned]] — бросили кешбэк-сервисы, потому что забывали ритуал-ссылку. Персоны [[persona-icp02-pavel]] (Core), [[persona-icp02-marina]] (скептик).
- **Боль/триггер, в который бьём:** «постоянно забывал перейти по ссылке и забил» (этап 6, тема №2) — кешбэк требовал дисциплины, которой нет.
- **Ведущий мотив:** простота / контроль (возврат без усилий).
- **Главный посыл (1 фраза):** «Кешбэк, который не надо помнить — браузер сам ловит покупку».
- **Выгода (что получит):** возврат с покупок без ссылок, расширений и ритуалов — просто покупаешь как обычно.
- **Доказательство (почему верить):** каждое начисление видно в истории операций со статусом «Проверяем» → подтверждено; вывод рублями на карту. (Против травмы «обещали — не выплатили».)
- **CTA:** «Поставь браузер — и забудь про ссылки».
- **Формат-кандидат:** короткое видео (до/после: «раньше — забыл ссылку, ноль; теперь — капнуло само»).
- **Гипотеза:** заходит лучше всего на Core ICP-02 (Павел), у которого боль ритуала спонтанна и подтверждена (Δ −0.3). На скептике (Марина) сработает слабее — ей нужнее доказательство выплаты (см. [[offer-02-payout-proof]]).
- **Метрика успеха:** CTR + конверсия в установку; вторично — доля активаций (первая засчитанная покупка).

## Варианты заголовков (для A/B)
1. «Кешбэк без единой ссылки — браузер ловит покупку сам».
2. «Бросил Letyshops, потому что забывал переходить по ссылке? Этот ловит сам».
3. «Покупай как обычно — кешбэк начислится без твоего участия».
